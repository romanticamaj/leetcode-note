# 矩陣問題工具箱：三大核心思維

解決矩陣問題時，與其尋找特定的解法，不如掌握一個由通用「工具」組成的思維框架。這個框架能幫助你分析問題，並組合出有效的解決方案。

---

## 工具一：尋找不變量 (Finding Invariants)

不變量是在特定遍歷路徑下，所有元素都共同遵守的數學或幾何屬性。找到不變量是將複雜的二維問題簡化為一維問題的關鍵。

**核心思想：** 將 `(i, j)` 座標壓縮成單一維度的特徵。

### 應用場景 1：對角線遍歷

- **不變量：** `i + j = sum`
- **分析：**
  - 在同一條「主對角線」方向的對角線上，所有元素的 `i + j` 之和都是一個常數 `sum`。
  - 在同一條「副對角線」方向的對角線上，所有元素的 `i - j` 之差都是一個常數。
- **策略：**
  1. 將外層迴圈從遍歷 `i` 或 `j`，改為遍歷不變量 `sum`。
  2. `sum` 的範圍是從 `0` 到 `m - 1 + n - 1`。
  3. 如此一來，問題就從「如何遍歷二維矩陣」簡化為「對於每一個 `sum`，如何找出對應的所有元素」。

### 應用場景 2：矩陣搜索優化（二維到一維映射）

- **不變量：** `index = i * n + j`（以及逆映射：`i = index / n`, `j = index % n`）
- **分析：**
  - 當矩陣每行有序且下一行首元素大於上一行末元素時，整個矩陣可視為邏輯上的一維有序數組 (2D sorted to 1D sorted)。
  - 通過建立二維座標與一維索引的映射關係，可將二維搜索轉換為一維二分搜索。
- **策略：**
  1. 將搜索空間從二維 `[0, m) × [0, n)` 轉換為一維 `[0, m*n-1]`。
  2. 在一維空間進行標準二分搜索，使用 `index` 作為搜索變數。
  3. 訪問元素時，用 `matrix[index / n][index % n]` 將一維索引映射回二維座標。

## 工具二：數學化邊界設計 (Mathematical Boundary Design)

在確定了遍歷路徑（例如，沿著某個不變量）後，下一步是精確地定義這個路徑的起點和終點。直接用數學公式計算邊界，通常比在迴圈內部使用 `if` 判斷更優雅、更高效。

**核心思想：** 將所有已知的約束條件（Constraints）結合起來，推導出遍歷變數的確切範圍。

**應用場景：對角線遍歷的邊界**

- **目標：** 在 `i + j = sum` 的條件下，找出 `i` 的合法範圍。
- **已知約束：**
  1.  `0 <= i <= m - 1` (來自矩陣的行邊界)
  2.  `0 <= j <= n - 1` (來自矩陣的列邊界)
- **推導過程：**
  1.  將 `j = sum - i` 代入約束 (2)，得到 `0 <= sum - i <= n - 1`。
  2.  整理關於 `i` 的不等式，得到 `sum - (n - 1) <= i <= sum`。
  3.  現在我們有兩組對 `i` 的約束，需要取它們的 **交集**：
      - `i` 必須大於等於 `0` **且** 大於等於 `sum - n + 1` => `i >= max(0, sum - n + 1)`
      - `i` 必須小於等於 `m - 1` **且** 小於等於 `sum` => `i <= min(m - 1, sum)`
- **結論：** `max(0, sum - n + 1) <= i <= min(m - 1, sum)`。這個公式看起來複雜，但它只是將所有基本約束條件系統性結合的結果。

## 工具三：座標變換 (Coordinate Transformation)

許多矩陣問題，特別是涉及旋轉、翻轉或對稱操作的問題，其本質是將一個座標 `(i, j)` 映射到另一個座標。

**核心思想：** 找到從舊座標到新座標的映射函數。

**應用場景：圖像旋轉**

- **目標：** 將 `n x n` 矩陣順時針旋轉 90 度。
- **變換函數：** `(i, j) -> (j, n - 1 - i)`
  - **直觀解釋：**
    - 新的行號 `i'` 就是舊的列號 `j`。
    - 新的列號 `j'` 是 `n - 1` 減去舊的行號 `i`。
- **策略：**
  1. **分層處理 (Layer-by-Layer)：** 將旋轉問題分解為處理一系列同心方框。外層迴圈遍歷 `layer`，從 `0` 到 `n / 2 - 1`。
  2. **循環交換 (Cyclic Swap)：** 直接應用變換函數會需要額外空間。要實現原地（in-place）交換，需要找到一個完整的變換循環。
     - `(i, j)`
     - `-> (j, n - 1 - i)`
     - `-> (n - 1 - i, n - 1 - j)`
     - `-> (n - 1 - j, i)`
     - `-> (i, j)` (回到原點)
  3. 在每一層中，遍歷其中一條邊上的元素，並對其對應的四個點進行一次循環交換。

## 總結

| 工具               | 核心思想           | 適用問題                                           |
| :----------------- | :----------------- | :------------------------------------------------- |
| **尋找不變量**     | 將二維問題降維     | 對角線遍歷、矩陣搜索優化、特定路徑求和             |
| **數學化邊界設計** | 用公式取代條件判斷 | 任何需要精確控制遍歷範圍的場景                     |
| **座標變換**       | 找到座標映射關係   | 旋轉、翻轉、對稱性問題                             |

當遇到新的矩陣問題時，可以從這三個工具的角度去思考：

1. 這個問題的遍歷路徑有什麼 **不變量** 嗎？
2. 我能用 **數學公式** 來精確描述遍歷的起點和終點嗎？
3. 這個問題是否可以看作是一種 **座標變換**？
