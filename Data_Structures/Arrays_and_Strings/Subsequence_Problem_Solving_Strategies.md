# 演算法心法：子序列問題攻略 (Subsequence Problem-Solving Strategies)

子序列（Subsequence）問題是演算法面試中的常客。一個序列的子序列是通過刪除零個或多個元素，並保持其餘元素相對順序不變而得到的。本篇旨在整理分析子序列問題的通用思路與解法。

---

## 1. 定義與暴力法分析

**定義：** 給定序列 `A`，若序列 `B` 是通過從 `A` 中刪除零個或多個元素，而不改變其餘元素順序得到的，則 `B` 是 `A` 的子序列。

**暴力法 (Brute-Force):**

對於原序列中的每一個元素，我們都有兩種選擇：**“選”** 或 **“不選”**。

- 如果原序列的長度為 `n`，那麼總共的可能性就是 `2 * 2 * ... * 2`（n 次），即 `2^n` 種。
- **時間複雜度:** `O(2^n)`。這種指數級的複雜度通常意味著暴力法只適用於 `n` 非常小（例如 `n <= 20`）的情況。在大多數問題中，這會導致超時。

---

## 2. 核心優化技巧

由於暴力法不可行，我們需要更高效的策略。子序列問題最常見的優化技巧是**動態規劃 (Dynamic Programming)**。

### 技巧一：動態規劃 (DP)

DP 是解決子序列問題的基石。其核心是定義一個 `dp` 陣列，其中 `dp[i]` 通常代表一個與**以 `nums[i]` 結尾的子序列**相關的狀態。

**經典案例：最長遞增子序列 (Longest Increasing Subsequence - LIS)**

> 給定一個整數陣列 `nums`，找到最長嚴格遞增子序列的長度。

- **DP 狀態定義:** `dp[i]` 表示以 `nums[i]` **結尾**的最長遞增子序列的長度。
- **狀態轉移方程:**
  - 為了計算 `dp[i]`，我們需要回顧所有在 `i` 之前的元素 `j` (`0 <= j < i`)。
  - 如果 `nums[i] > nums[j]`，這意味著 `nums[i]` 可以接在以 `nums[j]` 結尾的遞增子序列後面，形成一個更長的子序列。
  - 因此，`dp[i] = max(dp[i], dp[j] + 1)`。
  - `dp[i]` 的初始值為 `1`（即 `nums[i]` 本身構成一個長度為 1 的子序列）。
- **最終答案:** 最終的答案是 `max(dp[0], dp[1], ..., dp[n-1])`，因為最長遞增子序列可能在任何位置結束。
- **時間複雜度:** `O(n^2)`，因為計算每個 `dp[i]` 都需要一個 `O(n)` 的迴圈。

### 技巧二：貪心 + 二分搜尋 (Greedy with Binary Search)

對於某些特定問題（如 LIS），`O(n^2)` 的 DP 還可以進一步優化。

- **核心思想:** 維護一個“候選”的遞增子序列。對於每個新元素，我們用二分搜尋在這個候選序列中找到一個“最佳”位置來替換或擴展它。
- **LIS 的 `O(n log n)` 解法:**
  1. 維護一個陣列 `tails`，其中 `tails[i]` 表示所有長度為 `i+1` 的遞增子序列中，**結尾元素最小的值**。
  2. 遍歷 `nums` 中的每個元素 `num`：
     a. 使用二分搜尋 (`lower_bound`) 在 `tails` 中找到第一個大於或等於 `num` 的位置。
     b. 如果找到了，就用 `num` 替換掉該位置的元素。這意味著我們找到了一個潛在的、結尾更小的、同樣長度的遞增子序列。
     c. 如果沒找到（`num` 比 `tails` 中所有元素都大），就將 `num` 加到 `tails` 的末尾，表示最長遞增子序列的長度增加了 1。
  3. 最終 `tails` 的長度就是 LIS 的長度。
- **時間複雜度:** `O(n log n)`，因為 `n` 次遍歷，每次進行一次 `O(log n)` 的二分搜尋。

## 3. 問題變形與思路轉換

### 關於「只取 subsequence 長度」

如果只關心長度，問題是否可以退化？

- **順序的重要性：** 子序列問題的關鍵在於**維持相對順序**，所以它不能完全退化為不在乎順序的“多重集 (multi-set)”問題。
- **對 DP 的簡化：** 然而，“只關心長度”確實簡化了我們的 DP 狀態。我們不需要在 `dp` 狀態中儲存整個子序列（`vector<int>`），而只需要儲存一個數值（如長度、總和等）。這使得 DP 的實現變得高效。

### 其他常見子序列問題類型

- **計數問題 (Counting):** "有多少個滿足條件的子序列？" (e.g., LeetCode 940. Distinct Subsequences II)
  - `dp[i]` 通常表示以 `nums[i]` 結尾的滿足條件的子序列數量。
- **總和問題 (Summation):** "滿足條件的子序列的最大總和是多少？"
  - `dp[i]` 通常表示以 `nums[i]` 結尾的滿足條件的子序列的最大和。

**結論：** 無論問題如何變形，思考的出發點通常都是：**定義 `dp[i]` 為與以 `nums[i]` 結尾的子序列相關的某個最佳解。**
