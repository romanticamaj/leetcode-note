# 鏈表 (Linked List)

鏈表是一種線性數據結構，其中的元素不是存儲在連續的內存位置，而是通過指針連接。每個節點包含數據和指向下一個節點的指針。

## 解題前的關鍵觀察

在開始解決鏈表問題之前，請特別注意以下觀察點：

1. **鏈表類型**：確定是單向鏈表 (Singly Linked) 還是雙向鏈表 (Doubly Linked)

   - 單向鏈表：每個節點只有一個指向下一個節點的指針
   - 雙向鏈表：每個節點有兩個指針，分別指向前一個和後一個節點

2. **返回要求**：是否需要返回新的鏈表

   - 有些問題要求原地修改鏈表
   - 有些問題要求創建並返回新的鏈表
   - 有些問題要求返回題目指定的特定節點（如中間節點、倒數第 k 個節點等）

3. **空鏈表處理**：鏈表是否可能為空
   - 始終檢查 head 是否為 nullptr
   - 處理空鏈表的邊界情況
   - 在循環和遞歸中正確處理空指針

## 操作技巧

### 新增節點 (Adding Nodes)

新增節點的關鍵步驟：

1. **先更新新節點的連結**：因為新節點不會影響原有結構，所以先設置它的指針
2. **再更新原結構的連結**：最後修改原有結構中的指針，自然得到新的結構

### 刪除節點 (Removing Nodes)

刪除節點的關鍵步驟：

- **直接更新原結構的連結**：通過修改前&後一個節點的指針，繞過要刪除的節點，即可完成刪除操作

## 常見技巧

### 使用虛擬頭節點 (Dummy Node)

在處理鏈表時，使用虛擬頭節點可以簡化邊界情況的處理，特別是當可能需要修改頭節點時。

### 快慢指針 (Fast & Slow Pointers)

快慢指針是解決許多鏈表問題的有效技術，如檢測環、找中點等。

### K-Gap 指針 (K-Gap Pointers)

K-Gap 指針技巧使用兩個相距 k 個節點的指針，並以相同的速度移動，常用於查找倒數第 k 個節點、刪除倒數第 k 個節點等操作。

### 相鄰指針 (Adjacent Pointers)

相鄰指針是 K-Gap 指針的特例（k=1），兩個指針相鄰或僅相距一個節點，常用於反轉鏈表、交換節點等就地修改操作。

### 問題拆解策略

處理複雜的鏈表問題時，一個有效的心法是將問題拆解成多個基本的鏈表操作。

**示例：刪除鏈表的倒數第 k 個節點**

這個問題可以拆解為兩個基本操作：

1. 找到倒數第 k 個節點（或其前一個節點）
2. 執行刪除操作

**示例：反轉鏈表的一部分**

這個問題可以拆解為：

1. 找到要反轉部分的起始位置
2. 執行反轉操作
3. 重新連接鏈表

### While 循環條件設計

在鏈表操作中，while 循環條件的設計至關重要，它必須確保循環內的所有指針操作都可以安全執行。

```cpp
// 檢測鏈表中是否有環
bool hasCycle(ListNode *head) {
    auto slow = head;
    auto fast = head;

    while (slow && fast && fast->next) {
        slow = slow->next;        // 需要 slow != nullptr
        fast = fast->next->next;  // 需要 fast != nullptr 且 fast->next != nullptr

        if (slow == fast) return true;
    }

    return false;
}
```

**關鍵原則**：

- **💡 關鍵心法：fast and slow pointers 的 while condition 可以用 while loop 內的 pointer 使用情況來設計**
- while 循環的條件必須基於循環內的指針操作能夠正常執行
- 條件應該檢查所有可能導致空指針異常的情況
- 在處理多個指針時，每個指針的有效性都需要被檢查
