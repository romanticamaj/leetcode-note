# 心法：固定大小堆模式 (Fixed-Size Heap Pattern)

## 1. 適用場景

此模式適用於需要從一個資料集合或串流中，動態維護一個**固定大小**的「有界集合」的場景。最典型的應用是：

- **Top-K 問題**：找到最大或最小的 K 個元素。
- **有限資源模擬**：模擬一個只有 K 個容量的系統，並決定誰能留下。

## 2. 核心思想：Push-Pop 簡化策略

核心思想是**信任並利用堆的自平衡特性**，將傳統的、帶有複雜條件判斷的插入邏輯，轉化為一個固定的、兩步驟的操作序列：「**先推入，後平衡 (Push-then-Pop)**」。

- **傳統思路 (條件式插入)**：

  1. 檢查堆的大小是否小於 `k`。
  2. 如果是，直接插入。
  3. 如果不是，比較新元素與堆頂元素。
  4. 如果新元素更「優」，則彈出堆頂，再插入新元素。

  - **缺點**：邏輯分支多，程式碼冗長，在高壓環境下容易出錯。

- **Push-Pop 模式 (無條件插入與平衡)**：
  1. **`push` 新元素**：無條件將新元素推入堆中 (`O(log k)`)。這會讓堆暫時變為 `k+1` 大小。
  2. **`pop` 多餘元素**：若堆的大小超過 `k`，立即 `pop` 堆頂 (`O(log k)`)。堆會自動移除當前 `k+1` 個元素中最「不優」的那個，恢復到 `k` 大小。

這個模式用固定的兩步操作取代了複雜的 `if-else`，程式碼更簡潔、可讀性更高，且不易出錯。

## 3. 案例：Top K Frequent Elements (LeetCode 347)

**問題**：找到一個陣列中出現頻率最高的 `k` 個元素。

**策略**：使用一個大小為 `k` 的**小根堆 (min-heap)** 來維護頻率最高的 `k` 個元素。堆的比較基於**頻率**。

```cpp
// Push-Pop 模式：先操作，後平衡
// 使用 pair<frequency, number>，小根堆會按 frequency 排序
std::priority_queue<std::pair<int, int>,
                    std::vector<std::pair<int, int>>,
                    std::greater<std::pair<int, int>>> minHeap;

// 假設 countingMap 已儲存每個數字的頻率
for (auto const& [num, frequency] : countingMap) {
    // 步驟 1: 無條件 push，讓 heap 維護順序
    minHeap.push({frequency, num});

    // 步驟 2: 如果超出大小，無條件 pop，移除當前集合中頻率最小的元素
    if (minHeap.size() > k) {
        minHeap.pop();
    }
}
```

**為什麼用小根堆找「最大」的 K 個？**
因為我們希望堆頂是當前 `k` 個候選者中「最弱」的那個（即頻率最低的），這樣當一個更強的挑戰者（頻率更高的元素）出現時，我們可以輕易地將最弱者淘汰掉。
