# 心法：三步不變式維護 (Insert → Transfer → Rebalance)

在處理需要將資料流動態劃分為兩組，並同時維護這兩組之間**順序關係**和**大小平衡**的問題時，一種非常強大且優雅的設計模式是「三步不變式維護」。

這個模式的核心思想是，將複雜的條件判斷轉化為一個固定的、可預測的操作序列，從而簡化邏輯，降低出錯率。

## 核心概念：兩個不變式 (Invariants)

我們的目標是始終維持系統的兩種狀態屬性：

1. **分割不變式 (Partition Invariant)**：定義兩組資料之間的**數值關係**。例如，A 組中所有元素的值都必須小於或等於 B 組中的所有元素。
2. **平衡不變式 (Balance Invariant)**：定義兩組資料之間的**數量關係**。例如，A 組和 B 組的大小差距不能超過 1。

## 三步操作詳解

每次新增一個元素時，我們不試圖一次性滿足所有條件，而是遵循固定的三步流程，每一步專注於維護或恢復一個特定的不變式。

| 步驟                      | 操作                                                      | 目的與效果                                                                                                                                                                                         |
| :------------------------ | :-------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Insert (插入)**      | 將新元素 `num` 無條件地插入「主要組」(Primary)。          | **引入新元素**。這一步可能會暫時打破兩個不變式，但沒關係，我們的目標只是先將元素放入系統。                                                                                                         |
| **2. Transfer (轉移)**    | 從「主要組」取出其極端值，並轉移到「次要組」(Secondary)。 | **恢復「分割不變式」**。這一步是模式的精髓。通過將主要組中最「不應該」屬於它的元素（例如，小數堆中的最大值）轉移出去，我們強制恢復了兩組間的順序關係。                                             |
| **3. Rebalance (再平衡)** | **有條件地**從「次要組」取出其極端值，並移回「主要組」。  | **恢復「平衡不變式」**。在完成了分割後，檢查兩組的大小。如果次要組因接收了元素而變得過大，就從中取出一個最「適合」回到主要組的元素，以恢復大小平衡。這個操作被設計為不會破壞已經建立的分割不變式。 |

---

## 案例研究：動態資料流的中位數 (LeetCode 295)

這個問題是三步法的完美應用場景。

- **目標**：動態維護一個數字集合，並能隨時找到中位數。
- **結構**：
  - **主要組 (Primary)**：一個**大根堆 (max-heap)**，命名為 `small_half`，用來存放資料流中較小的一半數字。
  - **次要組 (Secondary)**：一個**小根堆 (min-heap)**，命名為 `large_half`，用來存放資料流中較大的一半數字。
- **不變式**：
  1. **分割不變式**：`small_half` 中的所有元素 ≤ `large_half` 中的所有元素。
  2. **平衡不變式**：`small_half.size()` 等於或比 `large_half.size()` 多一。

### `addNum(int num)` 的實現

```cpp
class MedianFinder {
private:
    std::priority_queue<int> small_half; // Max-heap
    std::priority_queue<int, std::vector<int>, std::greater<int>> large_half; // Min-heap

public:
    void addNum(int num) {
        // 步驟 1: Insert - 無條件將新元素加入代表「小半部」的 max-heap
        small_half.push(num);

        // 步驟 2: Transfer - 將「小半部」中的最大值轉移到「大半部」
        // 效果：強制執行了「分割不變式」。執行後，small_half 中所有元素必然 <= large_half 中所有元素。
        large_half.push(small_half.top());
        small_half.pop();

        // 步驟 3: Rebalance - 如果「小半部」的數量變得少於「大半部」，則進行再平衡
        // 效果：恢復了「平衡不變式」。
        if (small_half.size() < large_half.size()) {
            // 將「大半部」中的最小值移回「小半部」，這個操作不會破壞分割不變式。
            small_half.push(large_half.top());
            large_half.pop();
        }
    }

    double findMedian() {
        // 由於不變式被嚴格遵守，取中位數變得非常簡單
        if (small_half.size() > large_half.size()) {
            return small_half.top();
        }
        return (small_half.top() + large_half.top()) / 2.0;
    }
};
```

### 心法總結

這個看似有冗餘操作（先放進去又拿出來）的流程，實際上是將複雜的邏輯拆解為三個獨立、固定的步驟，每一步都有其明確的職責。這種「先污染，後治理」的策略，用可預測的固定操作取代了複雜的分支判斷，最終優雅地維護了兩個核心不變式，是演算法設計中一種非常高級的技巧。
