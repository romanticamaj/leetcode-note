# Hash Tables, Hash Maps, and Sets

## 概述

哈希表（Hash Table）是一種基於鍵值對（key-value pair）的數據結構，通過哈希函數將鍵映射到存儲桶（bucket）中，實現高效的數據存儲和檢索。

常見的哈希表實現包括：

- **Hash Map**：存儲鍵值對，每個鍵映射到一個值
- **Hash Set**：只存儲鍵，用於快速判斷元素是否存在

## 時間複雜度

| 操作 | 平均時間複雜度 | 最壞時間複雜度 |
| ---- | -------------- | -------------- |
| 查詢 | O(1)           | O(n)           |
| 插入 | O(1)           | O(n)           |
| 刪除 | O(1)           | O(n)           |

> **註：** 最壞時間複雜度 O(n) 發生在嚴重哈希衝突的情況下，例如當多個不同的鍵被哈希到同一個桶中，導致哈希表退化為鏈表。在實際應用中，通過良好的哈希函數設計和動態調整表大小，這種情況很少發生。

## 應用場景

### 優化查找操作

當你的算法需要頻繁檢查一個元素是否存在於集合中時（例如，`if ... in ...`），使用哈希表可以將時間複雜度從 O(n) 降低到 O(1)。

例如：

- 將 `if element in array` 操作（O(n)）優化為 `if element in hash_set`（O(1)）
- 將 `for each element in array, check if target - element exists in array`（O(n²)）優化為使用哈希表（O(n)）

### 常見應用

1. **查找/去重**：快速判斷元素是否已存在
2. **計數**：統計元素出現次數
3. **緩存**：存儲計算結果以避免重複計算
4. **映射關係**：建立鍵值之間的對應關係

### 計數應用 (Counting)

```
所謂「計數」，指的是追蹤事物的頻率。這意味著我們的哈希表將鍵映射到整數值。任何時候當你需要計數，都可以考慮使用哈希表來完成。
```

計數是哈希表的一個重要應用，將鍵映射到整數值來追蹤頻率：

```cpp
// C++ 使用 unordered_map 進行計數
unordered_map<string, int> counter;

// 增加計數
counter["apple"]++;

// 檢查元素是否存在（C++20）
if (counter.contains("apple")) {
    // 元素存在
}

// 檢查元素是否存在（C++17 及以前）
if (counter.find("apple") != counter.end()) {
    // 元素存在
}

// 獲取計數值
int count = counter["apple"];
```

- **元素頻率統計**：計算數組中每個元素出現的次數
- **字符頻率**：計算字符串中每個字符的出現頻率
- **模式匹配**：檢查兩個字符串是否具有相同的字符頻率模式（如字謎遊戲）
- **多數元素**：找出出現次數超過一半的元素
- **前綴和頻率**：計算特定前綴和出現的次數

#### 與 Sliding Window 結合

Counting 可以用 hash map (e.g., unordered_map) 達成，常常可以跟 sliding window 搭配：

- Sliding window 題目通常是找 subarray 滿足某個 constraint metric
- 這個 constraint metric 就可以用 hash map 來記錄
- Hash map 作為 `while WINDOW_IS_INVALID` 的比較來源
- 例如：限制窗口內不同字符的數量、元素出現頻率不超過 k 次等

## 實現技巧

1. **選擇合適的鍵**：確保鍵是可哈希的（hashable）
2. **處理衝突**：了解不同語言中哈希表衝突解決的機制
3. **空間與時間權衡**：哈希表通常以空間換時間
4. **邊建構，邊操作**：在建構哈希表的同時進行操作，而不是先完全建構再使用
5. **創建複合鍵**：將複雜數據結構轉換為可哈希的鍵

### 創建複合鍵 [Medium]

在某些情況下，我們需要使用複雜的數據結構（如數組、矩陣行、向量等）作為哈希表的鍵。由於這些數據結構本身通常不是可哈希的，我們需要將它們轉換為字符串或其他可哈希類型。

#### 使用 std::accumulate 創建字符串鍵

C++ 中可以使用 `std::accumulate` 將 vector 轉換為字符串作為哈希表的鍵：

```cpp
// 將整數向量轉換為字符串鍵
const string key = std::accumulate(begin(nums[r]), end(nums[r]), string(),
    [](string a, int b) {
        return std::move(a) + '-' + std::to_string(b);
    });

// 使用生成的鍵
hashMap[key] = value;
```

這種技術特別適用於：

- 需要將矩陣行或列作為鍵
- 需要將整個數組或向量作為鍵
- 需要將多維數據結構映射到一維鍵

#### 其他創建複合鍵的方法

1. **使用 tuple**：對於固定大小的複合鍵，可以使用 `std::tuple`
2. **自定義哈希函數**：為複雜數據結構定義專用的哈希函數
3. **位操作組合**：對於較小的整數值，可以使用位操作組合成一個整數鍵

### 邊建構，邊操作

在建構哈希表的過程中，可以同時進行查詢和比較操作，而不需要等到整個哈希表建立完成後再進行操作。

```cpp
// 傳統方法：先建構，再操作
// 步驟 1: 建構哈希表
unordered_map<int, int> map;
for (int i = 0; i < nums.size(); i++) {
    map[nums[i]] = i;
}
// 步驟 2: 使用哈希表進行操作
for (int i = 0; i < nums.size(); i++) {
    // 使用 C++20 的 contains 方法
    if (map.contains(target - nums[i])) {
        // 找到目標
    }
}

// 優化方法：邊建構，邊操作
unordered_map<int, int> map;
for (int i = 0; i < nums.size(); i++) {
    // 先檢查當前元素的配對元素是否已在哈希表中
    // 使用 C++20 的 contains 方法
    if (map.contains(target - nums[i])) {
        // 找到目標
    }
    // 然後再將當前元素加入哈希表
    map[nums[i]] = i;
}
```

這種方法特別適用於：

- 尋找配對元素（如 Two Sum 問題）
- 檢測重複元素
- 需要記錄元素出現次數的問題

## 常見問題模式

### Target Sum 問題

Target Sum 問題是一類常見的數組問題，要求找出數組中和為目標值的元素組合。哈希表是解決此類問題的高效工具。

#### 兩數之和 (Two Sum)

- **問題描述**：給定一個數組和一個目標值，找出數組中兩個數的和等於目標值
- **哈希表應用**：使用哈希表存儲已遍歷過的元素及其索引，對於每個元素，檢查目標值減去當前元素的結果是否在哈希表中
- **時間複雜度**：O(n)，只需一次遍歷

#### 三數之和 (Three Sum)

- **問題描述**：找出數組中三個數的和等於零的所有不重複三元組
- **解法思路**：通常結合排序和雙指針技術，也可以使用哈希表記錄已處理的元素
- **時間複雜度**：O(n²)

#### 子數組和等於 K (Subarray Sum Equals K)

- **問題描述**：找出數組中和為 K 的連續子數組的個數
- **哈希表應用**：使用哈希表存儲前綴和及其出現次數，對於每個前綴和，檢查 prefixSum - K 是否在哈希表中
- **時間複雜度**：O(n)

### 實現要點

1. **邊建構，邊查找**：在遍歷數組的同時，一邊將元素加入哈希表，一邊檢查互補元素是否已存在
2. **使用哈希表存儲什麼**：根據問題需求，可以存儲元素值、索引、頻率或前綴和
3. **處理重複元素**：根據問題要求，可能需要跳過重複元素或特殊處理

## 與其他數據結構的結合

哈希表常與其他算法技巧結合使用：

- **與 Sliding Window 結合**：維護窗口內元素的頻率或特性
- **與 Two Pointers 結合**：在一個指針遍歷的同時，使用哈希表記錄已訪問的元素
- **與 Prefix Sum 結合**：記錄前綴和的出現次數或位置
