# 圖論問題解題關鍵概念

圖論問題在算法競賽和面試中非常常見，但它們往往比其他數據結構的問題更難以分析和解決。本文檔將介紹解決圖論問題的關鍵概念和思考框架，幫助你更有效地分析和解決這類問題。

## 解題前的關鍵問題

在開始解決圖論問題之前，你應該先回答以下關鍵問題：

```
What are the nodes?
What are the edges?
Do you need state variables other than the node?
Where should the BFS/DFS start?
```

這些問題看似簡單，但它們能幫助你明確問題的本質，並為選擇合適的算法和數據結構奠定基礎。

### 1. 什麼是節點？(What are the nodes?)

節點代表圖中的實體。在不同的問題中，節點可能代表：
- 矩陣中的單元格 (row, col)
- 具有唯一 ID 的人或物體
- 狀態（如在遊戲或拼圖問題中）
- 字符串或其他複雜對象

**例子**：
- 在島嶼數量問題中，節點是矩陣中的每個單元格
- 在社交網絡問題中，節點可能是人
- 在單詞接龍問題中，節點是單詞

### 2. 什麼是邊？(What are the edges?)

邊代表節點之間的關係或連接。在不同的問題中，邊可能代表：
- 物理連接（如道路、電線）
- 邏輯關係（如朋友關係、依賴關係）
- 可能的轉換或移動（如在遊戲中）

**例子**：
- 在島嶼數量問題中，邊是相鄰的陸地單元格之間的連接
- 在社交網絡問題中，邊可能是朋友關係
- 在單詞接龍問題中，邊表示兩個單詞只相差一個字母

### 3. 是否需要除節點外的狀態變量？(Do you need state variables other than the node?)

有時，僅僅跟踪節點是不夠的，你可能需要額外的狀態信息：
- 到達節點的步數或距離
- 訪問節點時的條件（如攜帶的鑰匙、剩餘的燃料）
- 路徑信息（如從哪個節點到達當前節點）

**例子**：
- 在最短路徑問題中，需要跟踪到每個節點的距離
- 在帶鑰匙的迷宮問題中，需要跟踪持有的鑰匙集合
- 在有限步數內到達目標的問題中，需要跟踪已使用的步數

### 4. 從哪裡開始 BFS/DFS？(Where should the BFS/DFS start?)

選擇合適的起點對於解決問題至關重要：
- 單一起點（如指定的起始位置）
- 多個起點（如多源最短路徑問題）
- 所有可能的起點（如尋找所有連通分量）

**例子**：
- 在迷宮問題中，從入口開始
- 在多源最短路徑問題中，可以從所有源點同時開始 BFS
- 在尋找連通分量數量的問題中，需要嘗試從每個未訪問的節點開始

## 圖論問題的常見模式

### 1. 連通性問題

這類問題關注節點之間是否存在路徑，或者圖中有多少個連通分量。

**解題思路**：
- 使用 DFS 或 BFS 遍歷圖
- 使用訪問標記避免重複訪問
- 對於每個未訪問的節點，開始一次新的遍歷

### 2. 最短路徑問題

這類問題尋找從一個節點到另一個節點的最短路徑。

**解題思路**：
- 使用 BFS（對於無權圖）或 Dijkstra 算法（對於帶權圖）
- 使用 queue 存儲待訪問的節點
- 記錄到每個節點的距離

### 3. 拓撲排序問題

這類問題處理有向無環圖 (DAG) 中的依賴關係。

**解題思路**：
- 計算每個節點的入度
- 從入度為 0 的節點開始
- 逐步刪除節點及其出邊

### 4. 循環檢測問題

這類問題檢查圖中是否存在循環。

**解題思路**：
- 使用 DFS 並跟踪訪問狀態
- 使用三種狀態：未訪問、正在訪問、已訪問完成
- 如果在 DFS 過程中遇到「正在訪問」的節點，則存在循環

## 總結

解決圖論問題的關鍵在於：
1. 明確定義 vertex 和 edge
2. 確定是否需要額外的 state variable
3. 選擇合適的起點
4. 根據問題特性選擇合適的算法（DFS、BFS、Dijkstra 等）
5. 正確處理訪問標記和狀態轉移

通過回答本文開頭提出的四個關鍵問題，你可以更清晰地分析問題，並設計出高效的解決方案。
