# 通用 Graph 解題邏輯

---

## 1. 圖的基本性質

| 項目             | 說明                                   |
| ---------------- | -------------------------------------- |
| 表示方式         | Adjacency Matrix / List / Edge List    |
| 是否有向         | 有向圖或無向圖（無向圖需補雙邊）       |
| 是否有權重       | 有 → 使用 Dijkstra 或 Bellman-Ford     |
| 是否有 self-loop | 是否存在 `i == j` 的邊                 |
| 稠密或稀疏       | 稠密可直接用 matrix，稀疏建議轉為 list |

---

## 2. 任務分析

| 問題類型             | 常見需求                                   |
| -------------------- | ------------------------------------------ |
| 要解的是什麼？       | 連通性 / 路徑 / 成環 / 最短路 / 群組判斷等 |
| 起點是否固定？       | 固定起點 → 從指定點走；不固定 → 全圖走訪   |
| 是否有多 component？ | 有的話需從所有未 visited 節點展開          |

---

## 3. 解法選擇

| 方法         | 適用情境                       |
| ------------ | ------------------------------ |
| DFS / BFS    | 探索圖的結構、連通塊、層次關係 |
| Union-Find   | 判斷是否連通、計算群組數量     |
| Dijkstra     | 權重非負的最短路問題           |
| Bellman-Ford | 權重可能為負時的最短路         |
| Topo Sort    | 處理 DAG 的排序問題            |

---

## 4. 資料結構考量

| 問題                  | 說明                                           |
| --------------------- | ---------------------------------------------- |
| visited 陣列          | 必需，用來避免重複拜訪                         |
| queue / stack         | BFS 用 queue，DFS 用 stack 或遞迴              |
| parent / path 記錄    | 若需還原路徑則需紀錄父節點                     |
| 是否需轉換 graph 結構 | Edge List → 通常轉成 Adjacency List 使用更方便 |
| 起始點是否影響結果    | 多 component 或起點限定時需特別注意            |

---

## 5. 時間與空間

| 結構 / 操作          | 複雜度                          |
| -------------------- | ------------------------------- |
| Matrix 遍歷          | `O(n²)`                         |
| List 遍歷            | `O(n + e)`                      |
| DFS / BFS call stack | 最壞 `O(n)`                     |
| Space                | `O(n)` — visited + 遍歷輔助結構 |

---

## 範例：LeetCode 547. Number of Provinces

| 項目           | 說明                                 |
| -------------- | ------------------------------------ |
| 輸入           | `n x n` adjacency matrix             |
| 目標           | 回傳 province 數量（即圖的連通塊數） |
| 解法           | DFS 每遇未訪節點就展開一次，並計數   |
| 是否轉換結構   | 不需轉換，直接使用 matrix            |
| 是否需 visited | 需要，避免重複遍歷                   |
| 時間複雜度     | `O(n²)` — 掃描整張矩陣               |
| 空間複雜度     | `O(n)` — visited 陣列與遞迴堆疊      |

---

## 總結

解圖論題時，請先確認：

1. 圖的表示方式與特性（有無向、有無權）
2. 題目要你找什麼（路徑、群組、連通、圈）
3. 是否有多 component，是否要從多起點展開
4. 選擇合適的 traversal 方法與輔助結構
5. 明確分析時間與空間複雜度

掌握這五點，每道圖論題都能有系統地拆解。
