# 圖與樹的比較：遍歷與實現差異

樹是一種特殊的圖，它是無環連通圖的一種。雖然樹和圖在概念上有關聯，但在實現和遍歷方面存在顯著差異。本文檔將重點比較圖和樹的遍歷方法、實現細節以及處理循環的技巧。

## 基本結構差異

| 特性 | 樹 (Tree) | 圖 (Graph) |
|------|-----------|------------|
| 循環 | 無循環 | 可能有循環 |
| 根節點 | 有明確的根節點 | 沒有明確的起始點 |
| 父子關係 | 每個節點（除根節點外）有唯一的父節點 | 節點之間沒有明確的父子關係 |
| 連接性 | 所有節點都是連通的 | 可能有不連通的部分 |
| 方向性 | 通常是有向的（從父到子） | 可以是有向的或無向的 |
| 節點度數 | 在二叉樹中，每個節點最多有兩個子節點 | 節點可以有任意數量的鄰居 |

## 遍歷起點的差異

在樹的遍歷中，我們總是從根節點開始，這是一個明確的起點。但在圖中，沒有明確的起始節點，需要根據問題的具體要求選擇起點：

- 如果問題指定了起始節點，則從該節點開始遍歷
- 如果需要遍歷整個圖，可能需要從每個未訪問的節點開始遍歷
- 在某些問題中，可能需要嘗試從不同節點開始遍歷，以找到最優解

### 圖的遍歷起點選擇

遍歷整個圖（可能包含多個連通分量）時，需要遍歷所有節點，確保每個連通分量都被訪問到：

```cpp
void dfs(int node, vector<vector<int>>& graph, vector<bool>& visited) {
    visited[node] = true;
    
    // 處理當前節點
    // ...
    
    // 遍歷所有鄰居
    for (int neighbor : graph[node]) {
        if (!visited[neighbor]) {
            dfs(neighbor, graph, visited);
        }
    }
}

// 遍歷整個圖（包含多個連通分量）
void traverseGraph(vector<vector<int>>& graph) {
    int n = graph.size();
    vector<bool> visited(n, false);
    
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            // 從未訪問的節點開始新的遍歷
            dfs(i, graph, visited);
        }
    }
}
```

## 節點表示與鄰居訪問的差異

### 樹的節點表示與遍歷

在二叉樹中，節點通常有明確的結構，包含指向左右子節點的指針，遍歷時可以直接訪問子節點：

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

void traverseTree(TreeNode* root) {
    if (!root) return;
    
    // 處理當前節點
    // ...
    
    // 直接訪問左右子節點
    traverseTree(root->left);
    traverseTree(root->right);
}
```

### 圖的節點表示與遍歷

在圖中，節點的鄰居數量是不固定的，通常需要使用鄰接表或其他數據結構來表示，並使用循環遍歷所有鄰居：

```cpp
void traverseGraph(int node, vector<vector<int>>& graph, vector<bool>& visited) {
    visited[node] = true;
    
    // 處理當前節點
    cout << node << " ";
    
    // 使用循環遍歷所有鄰居
    for (int neighbor : graph[node]) {
        if (!visited[neighbor]) {
            traverseGraph(neighbor, graph, visited);
        }
    }
}
```

## DFS 實現的相似性

儘管圖和樹在結構上有差異，但 DFS 的基本實現模式是相似的。主要區別在於：

1. 圖需要使用 `visited` 數組來防止循環
2. 圖使用循環遍歷所有鄰居，而樹直接訪問左右子節點
3. 圖的遍歷可能需要從多個起點開始

## 處理循環的重要性

在樹中，由於沒有循環，我們可以直接遞歸遍歷而不用擔心無限循環。
但在圖中，特別是無向圖或有環的有向圖，必須使用 `訪問標記(visit)` 來防止重複訪問節點。

### 使用訪問標記防止循環

在圖的遍歷中，使用訪問標記（如 visited 數組）是防止循環的關鍵。
這確保了每個節點只被訪問一次，避免了無限循環的問題。上面的 DFS 代碼展示了如何使用訪問標記來安全地遍歷圖。

## 實際應用中的差異

### 樹的遍歷應用

在樹的遍歷中，我們通常關注：
- 前序、中序、後序遍歷的順序
- 節點的深度或高度
- 子樹的屬性（如大小、和、是否平衡等）

### 圖的遍歷應用

在圖的遍歷中，我們通常關注：
- 連通分量的識別
- 最短路徑的查找
- 循環的檢測
- 拓撲排序

## 總結：關鍵差異與相似點

### 關鍵差異

1. **起點選擇**：樹有明確的根節點作為起點，圖沒有明確的起點
2. **節點訪問**：樹直接訪問左右子節點，圖需要循環遍歷所有鄰居
3. **循環處理**：樹不需要處理循環，圖需要使用訪問標記防止循環
4. **連通性**：樹總是連通的，圖可能有多個連通分量
5. **遍歷完整性**：遍歷樹只需要一次 DFS/BFS，遍歷整個圖可能需要多次 DFS/BFS

### 相似點

1. **DFS/BFS 框架**：基本的 recursive 或 iterative 框架相似
2. **訪問順序**：都可以使用前序、中序、後序或層序遍歷
3. **問題解決模式**：許多問題都可以通過 DFS/BFS 遍歷來解決

## BFS 在圖中的特殊重要性：最短路徑

雖然 DFS 和 BFS 都可以用於遍歷圖，但在尋找最短路徑時，BFS 具有明顯的優勢。

### 圖中的「層級」(level) 概念

在樹中，我們通常談論節點的深度（與根的距離）。在圖中，雖然沒有明確的根節點，但我們可以將 BFS 的起始節點視為「根」，然後定義其他節點的「層級」為它們與起始節點的距離（最少邊數）。

### BFS 保證最短路徑

BFS 的工作原理決定了它總是按照節點與起始點的距離順序訪問節點。這意味著當 BFS 首次訪問一個節點時，它一定是通過最短路徑到達的。

### 樹與圖在最短路徑方面的區別

這是樹和圖在路徑查找方面的一個關鍵區別：

- 在樹中，任意兩點之間只有一條路徑，所以 DFS 和 BFS 都能找到最短路徑
- 在圖中，兩點之間可能有多條路徑，只有 BFS 能保證找到最短路徑
