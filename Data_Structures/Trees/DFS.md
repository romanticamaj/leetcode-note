# 深度優先搜索 (Depth-First Search, DFS)

## 基本概念

深度優先搜索是一種遍歷樹或圖的算法，它優先遍歷到樹的最深處，然後回溯。在二叉樹中，DFS 有三種主要變體：

- **前序遍歷 (Preorder Traversal)**: 根節點 → 左子樹 → 右子樹
- **中序遍歷 (Inorder Traversal)**: 左子樹 → 根節點 → 右子樹
- **後序遍歷 (Postorder Traversal)**: 左子樹 → 右子樹 → 根節點

## 實現方式

DFS 可以通過**遞歸**或**迭代**（使用 std::stack<TreeNode*>）來實現。

## DFS 的通用模板

DFS 在樹上的實現有一個通用的結構，幾乎適用於所有樹的 DFS 問題：

```cpp
ReturnType dfs(TreeNode* node) {
    // 1. 處理基本情況
    if (node == nullptr) {
        return baseResult;
    }

    // 2. 對當前節點進行邏輯處理
    // ...

    // 3. 遞歸調用子節點
    ReturnType leftResult = dfs(node->left);
    ReturnType rightResult = dfs(node->right);

    // 4. 根據子節點的結果計算當前節點的結果
    ReturnType result = combine(node->val, leftResult, rightResult);

    return result;
}
```

每個遞歸調用都是在解決同一個問題，只是輸入變成了當前節點為根的子樹。這種"自相似"的特性使得遞歸特別適合處理樹結構。

### 為什麼需要 if (node == nullptr) 作為終止條件呢？

檢查基本情況（如 `if (node == nullptr)`）不僅是為了終止遞歸，更是為了`避免空指針異常`。

如果不進行檢查，當遞歸到葉節點的子節點（null）時，嘗試訪問 `null->val` 或 `null->left` 等屬性會導致程序崩潰，因為 null 不具有這些屬性。

## ✅ DFS 解題關鍵心法 (重要!!!!)

1. **先拆解、完成基本的遞迴條件**

   - 包含 base case（終止條件）、recursion call（遞迴呼叫）、return value（回傳值）
   - 確保遞歸結構正確，避免 stack overflow 或錯誤邏輯

2. **根據遞迴條件的回傳值，與當前節點進行運算**

   - 將子問題的結果與當前節點結合，推導出整體解
   - 常見於最大值、總和、深度、條件統計等問題

3. **三種遍歷方式與解題思維**

在使用 DFS 解題時，可以從「何時處理當前節點」的角度，將 DFS 分為三種遍歷方式：

| 遍歷方式  | 處理順序               | 適用情境與思維角度                                       |
| --------- | ---------------------- | -------------------------------------------------------- |
| Preorder  | **當前節點 ➝ 左 ➝ 右** | 需要先處理當前節點（如建立副本、記錄路徑）               |
| Inorder   | **左 ➝ 當前節點 ➝ 右** | 常用於 BST 中序性質、排序相關問題                        |
| Postorder | **左 ➝ 右 ➝ 當前節點** | 需要先處理子節點再聚合結果（如計算子樹大小、最大路徑和） |

這三種方式本質上都是 DFS，只是根據遞迴中「處理當前節點」的時機不同，對應不同的解題策略與資訊流設計。

在設計 DFS 解法時，思考「我需要在遞迴前、中、後哪個時機處理當前節點？」可以幫助你選擇正確的遍歷方式與狀態傳遞方式。

## DFS 的變形：對稱遍歷 (Symmetric Traversal)

除了標準的前、中、後序遍歷，我們還可以透過交換左右子樹的遞迴順序，來創造出「對稱」的遍歷方式。這些變形在解決特定問題時非常有用。

### 核心思想

標準的 DFS 遍歷通常優先訪問左子樹。但如果我們**優先訪問右子樹**，就可以得到一個與標準遍歷「鏡像」或「對稱」的結果。

### 範例：根 -> 右 -> 左 (Pre-order 的對稱變形)

這是一種前序遍歷的對稱變形。標準的前序是「根 -> 左 -> 右」，而這個變形是「根 -> 右 -> 左」。

**應用場景：尋找每層最右邊的節點 (Right Side View)**

這個問題要求我們找到從右側看到的節點。如果我們使用「根 -> 右 -> 左」的順序進行 DFS，並結合 `level` 參數，那麼對於每一層，我們**第一個**訪問到的節點，就一定是該層最右邊的節點。

### 其他對稱變形

同樣地，我們也可以創造出中序和後序的對稱變形：

- **中序的對稱變形 (右 -> 根 -> 左)**：會得到一個**嚴格遞減**的有序序列（對於 BST）。
- **後序的對稱變形 (右 -> 左 -> 根)**：在需要優先處理右子樹結果時使用。

### 結論

不要被標準的前、中、後序遍歷所局限。理解 DFS 的本質是「遞迴地探索子問題」，這意味著我們可以根據問題的需求，靈活地調整遞迴呼叫的順序，來設計出最高效、最巧妙的解法。
