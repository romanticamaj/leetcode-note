# 關於 BST 中重複值的討論

**BST 的元素是否可以重複？**

這個問題沒有唯一的標準答案，取決於具體的定義：

1.  **嚴格定義 (Strict Definition)**：

    - 在最嚴格的定義下，BST 的所有節點值都必須是**唯一**的。
    - 左子樹的所有節點值都**小於**根節點值。
    - 右子樹的所有節點值都**大於**根節點值。
    - 這是許多教科書和演算法競賽（如 LeetCode）中常見的隱含假設。

2.  **寬鬆定義 (Permitting Duplicates)**：
    - 在某些實現中，允許 BST 包含重複值。
    - 處理重複值的常見約定是：將等於根節點值的元素始終放在**右子樹**（或始終放在左子樹）。
    - 例如，`left <= root < right` 或 `left < root <= right`。
    - C++ STL 中的 `std::multiset` 就是基於這種允許重複值的紅黑樹實現的。

**在 LeetCode 練習中該如何處理？**

- **預設假設**：除非題目特別說明，通常可以**假設 BST 不包含重複值**，或者重複值不影響問題的核心邏輯。
- **觀察範例**：檢查題目給定的範例中是否出現重複值。
- **釐清題意**：如果不確定，最好的做法是假設最嚴格的情況（不允許重複），或者在面試中向面試官釐清這個假設。

**結論**：雖然 BST 在理論上可以透過特定規則處理重複值，但在大多數演算法問題中，我們可以將其視為不包含重複元素的結構，以簡化問題。
