# Perfect Binary Tree（完美二元樹）

Perfect Binary Tree 是一種結構非常規則的二元樹，常用於理論分析與面試題中。理解其特性有助於推導 DFS/BFS 的時間與空間複雜度上限。

---

## ✅ 定義與特性

- 每個非葉節點都有兩個子節點（left 和 right）
- 所有葉節點都位於同一層級
- 節點總數為 `2^h - 1`，其中 `h` 是樹的高度（根節點為第 1 層）

---

## 🌲 範例結構

```
        1
      /   \
     2     3
    / \   / \
   4   5 6   7
```

---

## 📐 數學性質

| 項目         | 說明                         |
|--------------|------------------------------|
| 節點總數     | `2^h - 1`                    |
| 葉節點數     | `2^(h-1)`                    |
| 高度         | `log₂(n+1)`，n 為節點數      |
| 最底層節點   | 節點數的一半                 |

---

## 📌 應用場景

- 分析 DFS/BFS 的最壞空間複雜度
- 計算樹的最大深度、節點總數、葉節點數
- 作為理想化模型，與不平衡樹做對比

---

Perfect Binary Tree 是許多遞迴與遍歷問題的理論基礎，熟悉其結構有助於更快掌握樹的行為與分析技巧。
