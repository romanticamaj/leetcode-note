# Engineering Problem-Solving Playbook

This repository is a structured collection of notes, patterns, and mental models for mastering technical interviews and engineering problem-solving. It goes beyond simple LeetCode solutions to focus on the **"how" and "why"**—the reusable strategies, design principles, and testing frameworks that are the hallmarks of a professional engineer.

## Core Philosophy

The goal is not just to solve problems, but to build a durable, transferable skill set. This is achieved by:

1. **Extracting Patterns**: Distilling specific problems into abstract, reusable patterns (e.g., "One-Liner DFS", "Vertex Mapping").
2. **Systematic Thinking**: Applying structured frameworks for complex tasks like test case generation and algorithm design.
3. **Documenting Best Practices**: Capturing language-specific idioms, common pitfalls, and performance considerations (e.g., C++ `deque` implementations, integer overflow).

---

## Repository Structure

The repository is organized into high-level categories that represent the different facets of technical preparation.

### 🧠 Core Knowledge

- **`Data_Structures`**: In-depth notes on the implementation, trade-offs, and common patterns for fundamental data structures.
- **`Algorithms`**: Explanations and applications of key algorithms, focusing on the underlying strategy (e.g., Sliding Window, Two Pointers).
- **`System_Design`**: Concepts and strategies for designing scalable, distributed systems.
- **`CPP_Reference`**: C++ specific best practices, common mistakes, and implementation details of STL containers.

### 🚀 Application & Strategy

- **`Interview_Playbook`**: A collection of high-level strategies, checklists, and mental models for navigating the entire technical interview process. This includes pre-interview checklists, code review principles, and recursion design philosophies.
- **`Test_Case_Construction`**: A dedicated section on the critical skill of designing effective test cases, with multiple frameworks and data-structure-specific advice.
- **`Problem_Transformation`**: Frameworks for the meta-skill of reframing a problem into a more familiar or solvable form.

## How to Use This Repository

1. **Start with the Playbooks**: Begin with the `Interview_Playbook` and `Test_Case_Construction` folders to build a strong foundation for your approach.
2. **Deep Dive into Concepts**: Use the `Data_Structures` and `Algorithms` folders to study specific topics.
3. **Consult the Reference**: Refer to the `CPP_Reference` for language-specific questions and best practices.
4. **Contribute by Abstracting**: When you solve a new problem, don't just save the solution. Think about the underlying pattern and add it to the appropriate section.
