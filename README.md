# LeetCode Notes Repository

This repository is organized to store notes and solutions for LeetCode problems, primarily in C++.

## Repository Structure

The repository is organized by problem types and algorithms to make it easy to find and review specific categories of problems.

### Data Structures

- **Arrays_and_Strings**: Problems involving arrays, strings, and related operations
- **Linked_Lists**: Singly linked lists, doubly linked lists, and related problems
- **Trees**: 
  - Binary Trees
  - Binary Search Trees
- **Graphs**: Graph traversal, connectivity, and other graph-related problems
- **Hash_Tables**: Problems solved using hash tables, maps, and sets
- **Stacks_and_Queues**: 
  - Stacks
  - Queues
  - Monotonic Stacks
- **Heaps**: Priority queue problems and heap operations
- **Trie**: Prefix tree problems and implementations

### Algorithms

- **Binary_Search**: Problems involving binary search on sorted arrays or other data structures
- **Two_Pointers**: Problems solved using the two-pointer technique
- **Sliding_Window**: Problems involving sliding window algorithms
- **BFS_DFS**: Breadth-first search and depth-first search problems
- **Backtracking**: Problems involving backtracking algorithms
- **Dynamic_Programming**: 
  - 1D Dynamic Programming
  - 2D Dynamic Programming
- **Greedy**: Problems solved using greedy algorithms
- **Divide_and_Conquer**: Problems solved by breaking them down into subproblems
- **Bit_Manipulation**: Problems involving bit operations
- **Math**: Mathematical problems and number theory
- **Union_Find**: Disjoint set problems and implementations

### Additional Resources

- **System_Design**: Notes on system design problems
- **Templates**: Reusable code templates for common algorithms and data structures
- **Resources**: Additional notes, cheat sheets, and references

## How to Use This Repository

1. Navigate to the appropriate category folder based on the problem type
2. Add your notes and solutions in the corresponding folder
3. Use the templates folder for common algorithm patterns and data structure implementations

## Note

This repository is for personal use to store LeetCode notes and solutions. All notes and problem solutions will be added manually.
