# Greedy Algorithm Proofs：交換論證 (Exchange Argument)

## 核心關鍵

交換論證（Exchange Argument）是一種透過局部交換將任一最優解轉換為貪心解的證明技術，核心機制包括：

- 在最優解 O 與貪心解 G 的第一個不同選擇處，交換為貪心策略的選擇
  （此交換之所以成立，是因為貪心策略保證在該位置的選擇滿足特定的 cost 條件，例如最小結束時間或最大價值密度，從而保持後續可行性與最優性）。
- 重複以上交換步驟：假設最優解 O → 識別第一個不同點 → 交換得 O' → 重複直到 O 轉換為 G。

此過程的通用思路：

1. 假設存在最優解 O。
2. 與貪心解 G 比較，定位第一個不同之處。
3. 在該位置交換貪心策略的選擇，得到新的解 O'，並證明 O' 與 O 同樣最優。
4. 重複至 O 與 G 相同，證明 G 為最優解。

## 交換論證的通用步驟

1. **定義可行解結構**  
   明確問題中容器（解）的形式與約束。
2. **描述貪心選擇策略**  
   說明演算法每一步如何做出局部最優選擇。
3. **構造假設最優解 O**  
   假設存在最優解 O 並對其進行分析。
4. **識別交換點**  
   找到 O 與 G 的第一個不同選擇位置 i。
5. **執行交換**  
   用 G 的選擇替換 O 中的對應元素，得到 O'，並論證 O' 的目標值不差於 O。
6. **遞歸應用**  
   對剩餘子問題重複上述步驟，最終將 O 轉換為 G。

## 範例：活動選擇問題 (Activity Selection)

**問題描述**  
給定 n 個活動，每個活動有開始時間 `s_i` 與結束時間 `f_i`，要求選擇最多數量的不重疊活動。

**貪心策略**  
每次從剩餘活動中選擇結束時間最早的活動。

**交換論證**

1. 假設最優解 O 為 `[a₁, a₂, …, aₖ]`，貪心解 G 為 `[g₁, g₂, …, gₘ]`。最佳情形下 m = k。
2. 比較首選：若 `g₁ = a₁`，則繼續比較下一項；否則，由於貪心策略在剩餘活動中選擇了結束時間最早者 `g₁`，故 `f(g₁) ≤ f(a₁)`。
   進一步，最優解 O 的第二個活動 `a₂` 必定在 `a₁` 結束後才能開始，即 `s(a₂) ≥ f(a₁)`，因此有 `s(a₂) ≥ f(g₁)`。
   將 `a₁` 替換為 `g₁` 後，不會影響後續活動的可行性，得到新解 O'。
3. 對剩餘活動集合重複交換，最終 O 轉換為 G，證明貪心解最優。

## 應用：分數背包問題 (Fractional Knapsack)

**問題描述**  
給定 n 個物品，每個物品有重量 `w_i` 與價值 `v_i`，背包容量為 W，可分割物品。目標最大化總價值。

**貪心策略**  
按單位重量價值 `v_i / w_i` 降序裝入。

**交換論證**

1. 假設最優解 O 在某步選擇了單位價值較低的物品片段 x，而貪心解 G 選擇了單位價值較高的片段 y。
2. 交換過程：將 O 中等量的 x 換成 y，不改變容量，且能提升或保持總價值。
3. 重複交換，最終得到與 G 等價的方案，證明貪心解最優。

---

## 小結

交換論證通過局部交換，嚴謹地將任一最優解交換為貪心解，最終證明貪心策略的最優性。掌握此技巧，有助於快速驗證各種貪心算法的正確性與最優性。
