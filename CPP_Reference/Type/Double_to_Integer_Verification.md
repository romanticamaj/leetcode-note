# Double to Integer Verification (浮點數轉整數驗證)

這個技巧主要用於驗證一個浮點數運算的結果（通常是 `sqrt`）是否恰好為整數。

## 用途 (Usage)

最常見的應用場景是 **判斷完全平方數 (Perfect Square)**。
例如：檢查 `a^2 + b^2` 的和是否也是一個整數的平方（即尋找畢氏三元數）。

## 原理 (Principle)

利用 C++ 中 `double` 強制轉型為 `int` 會 **無條件捨去小數部分 (Truncate)** 的特性。

1. **Down-cast**: 將浮點數結果（如 `sqrt(sum)`）賦值給 `int` 變數。這會自動捨去小數部分。
2. **Restore & Verify**: 利用該整數進行逆運算（如平方），並與原始數值進行比較。

如果還原後的數值等於原始數值，則代表該浮點數運算的結果原本就是一個整數。

## 關鍵程式碼 (Key Code)

```cpp
// 假設我們要檢查 sum 是否為完全平方數
int sum = a * a + b * b;

// 1. 計算平方根 (得到 double)
double root = sqrt(sum);

// 2. Down-cast: 轉型為 int，捨去小數
int c = root;

// 3. Restore & Verify: 平方回去驗證是否等於原數
// 這裡使用整數乘法 c * c，避免了浮點數比較的精度問題
if (c * c == sum) {
    // sum 是完全平方數
    // c 是其整數平方根
}
```

### 為什麼不直接比較 `c == root`?

雖然 `if (c == root)` 在很多情況下也行得通，但 `c * c == sum` 是更穩健的做法：

1. **純整數運算**：`c * c == sum` 完全在整數域進行比較，避免了浮點數 `==` 比較的潛在風險。
2. **邏輯直觀**：它直接驗證了「`c` 的平方是否等於 `sum`」這個數學定義。
