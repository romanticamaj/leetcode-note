# Disjoint Set (Union-Find) - 核心概念

## 1. 什麼是 Disjoint Set？

Disjoint Set，又稱 Union-Find，是一種專門用來處理「不相交集合 (Disjoint Sets)」合併與查詢問題的資料結構。它能高效地回答兩個核心問題：

1. 查詢兩個元素是否屬於同一個集合。
2. 將兩個不相關的集合合併為一個集合。

**核心思想**:

> 讓所有在同一個連通分量 (connected component) 中的頂點，都指向同一個「代表節點」或「根節點 (root node)」。要檢查兩個頂點是否連通，我們只需要檢查它們是否擁有相同的根節點。

## 2. 核心操作

任何 Disjoint Set 的實作都圍繞著三個關鍵操作：

1. **`find(x)`**:

   - **目的**: 尋找元素 `x` 所在的集合的「代表節點」（即根節點）。
   - **用途**: 這是判斷連通性的基礎。

2. **`union(x, y)`**:

   - **目的**: 如果元素 `x` 和 `y` 分屬不同的集合，則將這兩個集合合併。
   - **機制**: 通常是透過將一個集合的根節點指向另一個集合的根節點來實現。

3. **`connected(x, y)`**:
   - **目的**: 判斷元素 `x` 和 `y` 是否在同一個集合中。
   - **實作**: 內部呼叫 `find` 函式，判斷 `find(x) == find(y)` 是否成立。

`find` 和 `union` 是 Disjoint Set 資料結構最根本的兩個函式，所有應用都是基於這兩者建構而成。
