# 位元操作 (Bit Manipulation) Playbook

位元操作是一種直接在位元層級上處理資料的技術。它不僅速度極快，而且在解決特定類型的問題時非常節省空間，例如處理狀態壓縮、集合運算或硬體層級的控制。

## TL;DR

| 操作 | 公式 | 說明 |
|------|------|------|
| 檢查位元 | `(x & (1 << i)) != 0` | 第 i 位是否為 1 |
| 設定位元 | `x \| (1 << i)` | 將第 i 位設為 1 |
| 清除位元 | `x & ~(1 << i)` | 將第 i 位設為 0 |
| 翻轉位元 | `x ^ (1 << i)` | 翻轉第 i 位 |
| 取最低位 1 | `x & -x` | Lowbit，取出最右邊的 1 |
| 清除最低位 1 | `x & (x - 1)` | 移除最右邊的 1 (zeroing out the least significant nonzero bit) |
| 全部位元為 1 | `~0` | 產生 0xFFFFFFFF |
| 計算 1 的個數 | `__builtin_popcount(x)` | GCC/Clang 內建 |

## 位元編號與數值

整數在記憶體中以二進位儲存，每個位元位置從右到左編號：

```text
位元編號:  31  30  ...  3   2   1   0
          ┌───┬───┬───┬───┬───┬───┬───┐
數值 13:  │ 0 │ 0 │...│ 1 │ 1 │ 0 │ 1 │
          └───┴───┴───┴───┴───┴───┴───┘
                       8   4   2   1   ← 位置權重 (2^i)
```

**關鍵對應：**

- 第 `i` 位的權重是 `2^i`（即 `1 << i`）
- 第 0 位 = 1, 第 1 位 = 2, 第 2 位 = 4, ...
- `int` 有 32 位元（位元 0~31），`long long` 有 64 位元（位元 0~63）

## 核心概念：位元遮罩 (Bitmask)

在許多情況下，我們只關心一個數字中的特定幾個位元，而不是全部。為了達到這個目的，我們使用**位元遮罩**（也簡稱為 **mask**）。一個 mask 通常是一個整數，其中一個或多個位元被設定為 1，用來對其他數字進行位元層級的操作。

舉例來說，假設我們想操作數字 `x` 的第 2 個位元（從右邊 0 開始索引，即代表十進位 4 的位元）。

我們可以建立一個 mask，將整數 `1` 向左移動兩位，得到 `100`（二進位）。現在，`x` 和這個 `mask` 之間的任何位元運算都只會「作用」在第 2 個位元上。

```cpp
int x = 13; // 二進位: 1101
int mask = 1 << 2; // 二進位: 0100
```

### 檢查位元 (Check Bit) 與取得位元 (Get Bit) - `&` 運算子

`&` 運算子有兩個重要用途：檢查位元狀態和取得特定位元。

#### 檢查位元 (Check Bit)

如果我們想檢查 `x` 的第 2 個位元是否為 1，我們可以使用 `&` (AND) 運算子。

`mask & x` 的結果只會在 `x` 的第 2 個位元為 1 時才不為零。

- **`&` (AND)**: `1 & 1 = 1`, `1 & 0 = 0`, `0 & 0 = 0`。

```cpp
// x = 1101, mask = 0100
//   1101 (x)
// & 0100 (mask)
// ------
//   0100 (結果為 4，非零)
bool is_bit_set = (x & mask) != 0; // true
```

#### 取得位元 (Get Bit)

除了檢查，`&` 也可以用來提取（isolate）特定位元的值：

```cpp
// 取得第 i 個位元的值 (0 或 1)
int get_bit = (x >> i) & 1;

// 或者，取得多個位元並保持其位置
int bits = x & mask;  // 保留 mask 為 1 的位元，其餘清零
```

**口訣：`& mask` 用於確認位元的真實性 (check) 或提取位元值 (get)。**

### 設定位元 (Set Bit) - `|` 運算子

如果我們想將 `x` 的指定位元設定為 1（無論它原來是什麼），我們可以使用 `|` (OR) 運算子。

- **`|` (OR)**: `1 | 1 = 1`, `1 | 0 = 1`, `0 | 0 = 0`。

```cpp
// x = 1001 (9), mask = 0100
//   1001 (x)
// | 0100 (mask)
// ------
//   1101 (結果為 13)
int result = x | mask;
```

**口訣：`| mask` 用於將位元設為真 (make it true)。**

### 清除位元 (Clear Bit) - `& ~` 運算子

如果我們想將 `x` 的指定位元強制設為 0（無論它原來是什麼），我們使用 `& ~` 組合。

```cpp
// x = 1101, mask = 0100
//   1101 (x)
// & 1011 (~mask)
// ------
//   1001 (結果為 9，第 2 位元被清除)
int result = x & ~mask;
```

**口訣：`& ~mask` 用於將位元設為假 (make it false)。**

### 翻轉位元 (Flip Bit) - `^` 運算子

如果我們想翻轉 `x` 的指定位元（1 變 0，0 變 1），我們可以使用 `^` (XOR) 運算子。

- **`^` (XOR)**: `1 ^ 1 = 0`, `1 ^ 0 = 1`, `0 ^ 0 = 0`。

一個簡單的思考方式是：

- `x XOR 0`：`x` 不變。
- `x XOR 1`：`x` 被翻轉。

```cpp
// 情況 1: x = 1101, mask = 0100
//   1101 (x)
// ^ 0100 (mask)
// ------
//   1001 (結果為 9，第 2 位元從 1 變 0)

// 情況 2: x = 1001, mask = 0100
//   1001 (x)
// ^ 0100 (mask)
// ------
//   1101 (結果為 13，第 2 位元從 0 變 1)
```

**口訣：`^ mask` 用於翻轉 (flip) 位元。**

### 進階技巧：Lowbit 與清除最低位

#### 取最低位的 1 (Lowbit)

```cpp
int lowbit = x & -x;  // 或 x & ~(x - 1)
```

**原理：** `-x` 是 `x` 的二補數，等於 `~x + 1`。這會讓最低位的 1 以下全變成 0，AND 後只保留那個 1。

```cpp
// x = 1100 (12)
// -x = 0100 (two's complement)
// x & -x = 0100 (4)
```

#### 清除最低位的 1

```cpp
int cleared = x & (x - 1);
```

**原理：** `x - 1` 會把最低位的 1 變成 0，並把它右邊的 0 都變成 1。AND 後消除最低位的 1。

```cpp
// x     = 1100 (12)
// x - 1 = 1011 (11)
// x & (x-1) = 1000 (8)
```

**應用：** 計算 1 的個數（Brian Kernighan 演算法）

```cpp
int count = 0;
while (x) {
    x = x & (x - 1);
    count++;
}
```

**與 Binary Indexed Tree（Fenwick Tree）的連結：** Prefix Query 的 `i -= i & -i` 等價於 `i &= i - 1`，都是清除最低位的 1。前者強調扣掉剛處理完的區間長度，後者強調位元變化；詳見 [BIT Query](../../Data_Structures/Advanced/Binary_Indexed_Tree/01-Core_Concepts.md#為什麼-query-減掉-lowbit與清除最低位-1-的關係)。
