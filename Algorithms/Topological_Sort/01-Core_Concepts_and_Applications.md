# 拓撲排序：核心概念與應用

拓撲排序 (Topological Sort) 是對一個有向無環圖 (Directed Acyclic Graph, DAG) 的頂點 (vertices) 進行線性排序，使得對於圖中每一條從頂點 `u` 指向頂點 `v` 的有向邊，頂點 `u` 都會出現在頂點 `v` 之前。

## 關鍵屬性

- **輸入 (Input):** 必須是一個有向無環圖 (DAG)。如果圖中包含環 (cycle)，則無法進行拓撲排序。
- **輸出 (Output):** 一個頂點的線性序列。
- **非唯一性 (Non-uniqueness):** 一個圖可以有多個合法的拓撲排序結果。

## 核心應用

- **任務排程 (Task Scheduling):** 給定一組具有依賴關係的任務（例如，任務 A 必須在任務 B 之前完成），拓撲排序可以提供一個有效的任務執行順序。
- **課程先修順序 (Course Prerequisites):** 在大學的課程規劃中，拓撲排序可以決定課程的修習順序。
- **依賴解析 (Dependency Resolution):** 用於軟體套件管理器和編譯系統中，以決定編譯和安裝的順序。
