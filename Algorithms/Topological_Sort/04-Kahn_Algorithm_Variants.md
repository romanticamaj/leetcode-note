# Kahn 演算法的變體與應用

Kahn 演算法主要用於拓撲排序，但它也可以被調整來解決其他涉及迭代移除特定屬性節點的圖論問題。本文件探討其一些強大的變體。

---

## 1. 在類樹圖中尋找重心 (LeetCode 310. Minimum Height Trees)

一個類似 Kahn 演算法的關鍵應用是，在具有樹狀結構的無向圖中尋找其重心（Centroids）。

### 直觀理解：剝洋蔥的比喻

如果我們將圖看作一個洋蔥（或一個圓），那麼葉節點（度為 1 的節點）就是最外層。核心思想是迭代地「剝除」這些外層。最終留下的節點就是圖的重心。

- **重心 (Centroids):** 這些是最中心的節點，意味著它們距離所有邊緣（葉）節點最近。對於任何類樹圖，重心的數量不超過 2 個。

透過重複移除葉節點，我們一步步向圖的中心靠近。這個過程保證會終止，最後剩下的一或兩個節點，便是能最小化到圖中任一節點最大距離的節點，這也正是最小高度樹（Minimum Height Trees）樹根的定義。

### 演算法調整

標準的 Kahn 演算法修改如下：

1. **初始化:**

   - 建立圖的鄰接串列，並計算每個節點的度（degree）。
   - 初始化一個佇列（或類似的資料結構），將所有葉節點（度為 1 的節點）加入其中。

2. **迭代剝離:**

   - 當圖中剩餘的節點總數大於 2 時：
     - 處理佇列中當前的所有節點（這構成一個「層」）。假設節點數量為 `size`。
     - 將節點總數減去 `size`。
     - 對於被移除的 `size` 個節點中的每一個：
       - 遍歷其所有鄰居。
       - 將鄰居的度減一。
       - 如果一個鄰居的度變為 1，它就成為了*新的*內部圖的葉節點，將其加入佇列。

3. **結果:**
   - 當迴圈終止時，佇列中剩餘的節點就是原始圖的重心，也就是最小高度樹的樹根。

## 2. 實作變體：使用 Vector 取代 Queue

在迭代剝離的過程中，同一層內節點的處理順序並不重要。因此，佇列的先進先出（FIFO）特性並非絕對必要。我們可以使用一個 `std::vector` 來儲存當前層的所有葉節點。

### 實作步驟

1. **初始化:**

   - 建立一個 `vector<int> leaves` 並填入初始的葉節點。

2. **使用 Vector 進行迴圈:**

   - 當節點總數 `n` 大於 2 時：
     - 將 `n` 減去 `leaves` 向量的當前大小。
     - 建立一個 `vector<int> new_leaves` 來儲存下一次迭代的葉節點。
     - 對於 `leaves` 向量中的每一個 `leaf`：
       - 對於 `leaf` 的每一個 `neighbor`：
         - 將 `neighbor` 的度減一。
         - 如果 `neighbor` 的度變為 1，則將其加入 `new_leaves`。
     - 處理完所有當前的葉節點後，交換 `leaves` 和 `new_leaves` 的內容 (`leaves.swap(new_leaves)`)。

3. **結果:**
   - 最終的 `leaves` 向量包含的即是重心。

這種方法有時可能效率稍高，因為它可能具有更好的快取局部性（cache locality），並避免了佇列資料結構的開銷。其迭代移除層的核心邏輯保持不變。

## 3. DAG Level Ordering (層次排序)

Kahn 演算法的內在運作機制，使其天然成為一種對有向無環圖（DAG）進行**層次排序（Level Ordering）**的演算法。這可以視為是樹的層序遍歷（Level-Order Traversal）在 DAG 上的延伸。

### 核心思想

- **Level 0 (第 0 層):** 所有入度（in-degree）為 0 的節點構成了圖的第一層。它們是所有依賴鏈的起點，不依賴於任何其他節點。
- **逐層推進:** 當我們處理完第 0 層的所有節點，並想像將它們及其所有出邊（out-edges）從圖中「移除」後，會有一些新的節點其入度變為 0。這些新節點就構成了 **Level 1 (第 1 層)**。
- **演算法過程:** Kahn 演算法的每一輪迭代（即處理佇列中當前所有節點的過程）都對應著圖中的一個「層次」。我們可以輕易地在演算法中加入一個計數器來追蹤當前的層級。

### 應用場景

這種變體對於解決需要知道節點在依賴關係中所處「深度」或「階層」的問題非常有用。例如：

- **平行任務排程:** 在一組有依賴關係的任務中，同一層的任務可以並行執行。層次排序可以找出每一批可以同時開始的任務。
- **最長路徑問題:** 在 DAG 中，從起點到某個節點的最長路徑長度，通常與該節點所在的層級有關。
