# 內省排序 (Introsort) - C++ `std::sort` 的核心

Introsort（內省排序）是 C++ 標準庫中 `std::sort` 的核心實現，由 David Musser 於 1997 年提出。它並非一種全新的排序演算法，而是一種**混合式 (Hybrid)** 排序策略，旨在結合多種演算法的優點，以提供快速的平均效能和最佳化的最壞情況效能。

## 1. 核心概念

Introsort 的核心是**以快速排序 (Quicksort) 為主體，並透過監控遞迴深度，在特定情況下切換到其他排序演算法，以彌補快速排序的缺陷**。這種「趨吉避凶」的設計使其極為高效和穩健。

其混合策略包含兩個關鍵的切換點：

1. 當遞迴深度過深時，切換到 **堆積排序 (Heap Sort)**，以保證最壞情況下的效能。
2. 當處理的資料規模足夠小時，切換到 **插入排序 (Insertion Sort)**，以利用其在小陣列上的高效率。

## 2. 演算法流程 (虛擬碼)

此虛擬碼參考自維基百科，展示了 Introsort 的核心流程。

```
procedure sort(A : array):
    maxdepth ← floor(log2(length(A))) × 2
    introsort(A, maxdepth)

procedure introsort(A, maxdepth):
    n ← length(A)
    if n < 16:
        insertionsort(A)
    else if maxdepth = 0:
        heapsort(A)
    else:
        p ← partition(A)  // 假設此函式包含基準點(pivot)選擇，p 為其最終位置
        introsort(A[1:p-1], maxdepth - 1)
        introsort(A[p+1:n], maxdepth - 1)
```

## 3. 混合策略的設計哲學

Introsort 的精髓在於其聰明的演算法選擇，以下是其兩個關鍵「保險機制」背後的原因。

### 為何在遞迴深度超限時切換到「堆積排序」？

- **目的**：偵測並阻止快速排序因分割區極度不平衡而導致的 `O(n²)` 最壞情況。
- **偵測方式**：當遞迴深度超過預設閾值（如 `2 * log n`）時，即視為進入了異常狀態。
- **為何是堆積排序？** 選擇備用方案需滿足兩個核心要求：

  1. **最壞情況時間複雜度為 O(n log n)**：這是補償快速排序缺陷的硬性指標。
  2. **原地排序 (In-place)**：空間複雜度需為 `O(1)` 或 `O(log n)`，以符合 `std::sort` 的設計。

  評估其他選項：

  - **Bubble/Insertion/Selection Sort**：它們的最壞情況時間複雜度都是 `O(n²)`，無法解決問題，因此不適用。（註：插入排序僅用於處理極小規模的子陣列，此時其 `O(n²)` 特性影響甚微）。
  - **Merge Sort**：時間複雜度達標，但標準實作需要 `O(n)` 的額外空間，違反了原地排序的要求。
  - **Heap Sort**：完美滿足所有條件。其**最壞情況時間複雜度穩定在 O(n log n)**，並且是**原地排序**。因此，它是在不犧牲空間效率的前提下，為快速排序提供效能安全網的理想選擇。

### 為何在小數據規模下切換到「插入排序」？

- **目的**：優化處理小規模分割區的實際執行效率。
- **偵測方式**：當待排序的分割區大小小於某個閾值（如 16 或 32）時。
- **為何是插入排序？** 這是基於實務效能的權衡：
  - **低額外開銷 (Low Overhead)**：快速排序的遞迴和分區操作有固定的效能開銷。對於小陣列，這些開銷佔比過高。
  - **高效率的簡單操作**：插入排序的內部迴圈僅包含簡單的比較和賦值，雖然理論複雜度是 `O(n²)`，但當 `n` 很小時，其絕對執行時間反而更短。
  - **快取友好 (Cache-Friendly)**：插入排序循序存取相鄰記憶體，具有良好的記憶體局部性，能有效利用現代 CPU 的快取。

因此，在遞迴的末端，切換到插入排序來完成「收尾工作」，是一種非常高效的優化手段。

## 4. 屬性與複雜度

- **穩定性 (Stability)**：**不穩定 (Unstable)**，因其主體是快速排序。
- **原地性 (In-Place)**：是，僅需 `O(log n)` 的遞迴堆疊空間。
- **時間複雜度**: 最差/平均/最佳情況 皆為 **O(n log n)**
- **空間複雜度**: **O(log n)**

## 5. 總結

Introsort 是混合演算法設計的典範，它不發明新演算法，而是聰明地組合現有演算法，揚長避短，從而創造出一個在各種情況下都表現出色的通用工具。這使得 `std::sort` 成為對 `std::vector` 等容器進行排序時，最可靠和高效的預設選擇。
