# 插入排序 (Insertion Sort)

## 1. 核心概念與分區 (Concept & Partition)

插入排序的核心思想可比喻為**整理手中的撲克牌**：將牌組分為「已排序」和「未排序」兩部分，每次從未排序部分抽一張牌，插入到已排序部分的正確位置。

演算法在邏輯上將陣列劃分為兩個動態區間：

1. **已排序區間 (Sorted Partition)**：位於陣列的**前端**，從 `arr[0]` 開始，長度逐漸增加。
2. **未排序區間 (Unsorted Partition)**：位於陣列的**後端**，是待處理的元素。

演算法重複地從「未排序區間」取出第一個元素，在「已排序區間」內從後向前掃描，找到合適位置並插入。

### 與選擇排序的比較

- **插入排序**：假設當前元素之前的序列已有序，然後將當前元素**插入**到這個有序序列的正確位置。
- **選擇排序**：從整個未排序區間**選擇**出最小（或最大）的元素，將其與未排序區間的邊界元素交換。

## 2. 範例程式碼 (C++)

### CLRS 版本 (移動元素)

此版本遵循《演算法導論》(CLRS) 的思想，將較大的元素逐一向右移動以騰出空間，最後完成插入。

```cpp
#include <vector>

void insertionSortCLRS(std::vector<int>& arr) {
    for (int j = 1; j < arr.size(); ++j) {
        int key = arr[j];

        // 將 arr[j] 插入 sorted arr[1..j - 2]
        int i = j - 1;
        while (i >= 0 && arr[i] > key) { // 將大於 key 的元素向右移動
            arr[i + 1] = arr[i];
            i = i - 1;
        }
        arr[i + 1] = key; // 插入 key
    }
}
```

### Swap 版本 (交換元素)

此版本透過與前一個元素反覆交換，將目標元素「冒泡」至其在已排序區間的正確位置，程式碼更為直觀。

```cpp
#include <vector>
#include <algorithm> // 用於 std::swap

void insertionSortSwap(std::vector<int>& arr) {
    for (int i = 1; i < arr.size(); ++i) {
        int j = i;

        while (j > 0 && arr[j] < arr[j - 1]) {
            std::swap(arr[j], arr[j - 1]);
            j--;
        }
    }
}
```

## 3. 迴圈不變量 (Loop Invariant)

插入排序的外層 `for` 迴圈（以 `j` 為索引）維持著以下不變量：

> 在每次迭代開始時，子陣列 `arr[0...j-1]` 包含了從原始陣列 `arr[0...j-1]` 中取出的元素，但這些元素本身是**已排序**的。

- **初始化**：`j=1` 時，子陣列 `arr[0...0]` 僅含一個元素，自然有序。
- **維持**：內層 `while` 迴圈為 `arr[j]` 在已排序的 `arr[0...j-1]` 中找到正確位置並插入，使 `arr[0...j]` 在下一次迭代開始前保持有序。
- **終止**：`j` 達到 `arr.size()` 時，`arr[0...size-1]` 全部有序。

## 4. 屬性 (Properties)

- **穩定性 (Stability)**：插入排序是**穩定 (Stable)** 的。比較時使用嚴格大於 (`>`) 或小於 (`<`)，相等元素不會觸發交換或移動，因此其原始相對順序得以保留。
- **原地性 (In-Place)**：插入排序是**原地 (in-place)** 的，僅需常數級別的額外空間。

## 5. 複雜度與適用場景

### 複雜度分析

- **時間複雜度 (Time Complexity)**

  - **最差/平均情況: O(n²)**：當輸入陣列逆序或隨機時。
  - **最佳情況: O(n)**：當輸入陣列已大致有序時，內層迴圈執行次數極少。

- **空間複雜度 (Space Complexity): O(1)**

### 適用場景：為何插入排序依然重要？

1. **處理近乎有序的陣列 (Nearly Sorted Arrays)**
   當陣列的逆序對數量很少時，插入排序效能極佳，時間複雜度趨近於 O(n)。

2. **處理小規模陣列 (Small Arrays)**
   對於小規模輸入，插入排序的常數因子小，實際執行速度常超過理論上更優但有額外開銷的演算法（如快速排序）。

**問：C++ 的 `std::sort` 也會這樣做嗎？**

**是的**。現代 C++ 標準庫的 `std::sort` 實現（通常為 Introsort）是一種混合排序。它在處理大規模資料時使用快速排序，並在遞迴到小規模子陣列時，**切換到插入排序**來完成最終排序，以兼顧各種情況下的效能與穩健性。
