# 選擇排序 (Selection Sort)

## 1. 核心概念

選擇排序的核心思想是將陣列邏輯上劃分為兩個部分：

1. **已排序區間 (Sorted Partition)**：位於陣列的前端，所有元素都已按順序排列。
2. **未排序區間 (Unsorted Partition)**：位於陣列的後端，是待排序的元素。

演算法的運作方式如下：
在每一輪迭代中，從**未排序區間**中尋找最小的元素，然後將其與**未排序區間**的第一個元素進行交換。完成交換後，這個最小的元素就成為**已排序區間**的最後一個成員。

這個過程會不斷重複，直到**未排序區間**為空，整個陣列排序完成。

## 2. 範例程式碼 (C++)

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // For std::swap

void selectionSort(std::vector<int>& arr) {
    // 外層迴圈控制已排序區間的邊界
    for (int i = 0; i < arr.size(); ++i) {
        // 假設未排序區間的第一個元素是最小的
        int min_idx = i;

        // 內層迴圈在未排序區間中尋找真正的最小值
        for (int j = i + 1; j < arr.size(); ++j) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }

        // 如果找到了更小的值，就將它與未排序區間的第一個元素交換
        std::swap(arr[i], arr[min_idx]);
    }
}
```

## 3. 優化版本與進階討論

### 優化版本程式碼

這個版本在兩個地方進行了微小的優化，以減少不必要的操作：

1. 外層迴圈只執行到 `n-1`。
2. 在交換前檢查 `min_idx != i`，避免與自身交換。

```cpp
#include <iostream>
#include <vector>
#include <algorithm> // For std::swap

void selectionSortOptimized(std::vector<int>& arr) {
    int n = arr.size();
    // 外層迴圈控制已排序區間的邊界
    for (int i = 0; i < n - 1; ++i) {
        // 假設未排序區間的第一個元素是最小的
        int min_idx = i;

        // 內層迴圈在未排序區間中尋找真正的最小值
        for (int j = i + 1; j < n; ++j) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }

        // 如果找到了更小的值，且該值不是目前位置的元素，才進行交換
        if (min_idx != i) {
            std::swap(arr[i], arr[min_idx]);
        }
    }
}
```

### 迴圈不變量 (Loop Invariant)

**這個演算法維持了什麼迴圈不變量？**

選擇排序的外層 `for` 迴圈（以 `i` 為索引）維持著以下**迴圈不變量**：

> 在每次迭代開始時，子陣列 `arr[0...i-1]` 包含了整個陣列中 `i` 個最小的元素，並且它們是**已排序**的。

我們來驗證這個不變量：

- **初始化 (Initialization)**：在第一次迭代開始前（`i = 0`），子陣列 `arr[0...-1]` 是空的。這個空集合當然包含整個陣列中 0 個最小的元素，並且是已排序的。條件成立。
- **維持 (Maintenance)**：假設在某次迭代 `i` 開始前，`arr[0...i-1]` 包含了陣列中 `i` 個最小且已排序的元素。在這次迭代中，演算法會在剩餘的 `arr[i...n-1]` 中找到最小值，並將其與 `arr[i]` 交換。因此，在下一次迭代 `i+1` 開始前，`arr[i]` 將會是第 `i+1` 小的元素。所以，`arr[0...i]` 就包含了 `i+1` 個最小的元素，並且它們是已排序的。條件得以維持。
- **終止 (Termination)**：當迴圈終止時（對於優化版本，`i` 最終等於 `n-1`），根據不變量，子陣列 `arr[0...n-2]` 包含了陣列中 `n-1` 個最小的元素，並且是已排序的。這意味著剩下的最後一個元素 `arr[n-1]` 必然是最大的元素。因此，整個陣列 `arr[0...n-1]` 都已排序。

### 為何外層迴圈只需要執行 n-1 次？

**為什麼演算法只需要對前 `n-1` 個元素執行，而不是全部 `n` 個元素？**

這直接源於我們上面討論的迴圈不變量。

當外層迴圈完成了 `n-1` 次迭代後（即 `i` 從 `0` 到 `n-2`），`arr[0...n-2]` 這 `n-1` 個位置都已經被填入了整個陣列中最小的 `n-1` 個元素。

此時，只剩下最後一個位置 `arr[n-1]`。由於前 `n-1` 個最小的元素都已經被放置在它們最終應該在的位置上，那麼剩下的這個元素必然是整個陣列中最大的元素。它自然而然地就位於正確的排序位置上，不再需要任何比較或交換。

因此，對第 `n` 個元素（索引為 `n-1`）執行迴圈是多餘的，演算法只需執行 `n-1` 次即可保證整個陣列的有序性。

## 4. 穩定性 (Stability)

選擇排序是一種 **不穩定 (Unstable)** 的排序演算法。

穩定性是指當序列中存在相等元素時，排序後它們的相對位置是否保持不變。選擇排序在交換元素時，可能會打亂相等元素的原始順序。

**範例：**
假設有序列 `[5a, 8, 5b, 2, 9]`，其中 `5a` 和 `5b` 值相等，但為了區分，我們加上標記。

1. 第一輪，找到最小值 `2`，將其與 `5a` 交換。序列變為 `[2, 8, 5b, 5a, 9]`。
2. 此時，`5a` 和 `5b` 的相對順序已經被改變了 (`5b` 現在在 `5a` 的前面)。

因此，選擇排序是不穩定的。

## 5. 複雜度分析 (Complexity Analysis)

- **時間複雜度 (Time Complexity): O(n²)**

  - 無論輸入資料的初始狀態如何，選擇排序都需要兩層巢狀迴圈來完成。
  - 外層迴圈執行 `n-1` 次。
  - 內層迴圈執行 `(n-1) + (n-2) + ... + 1` 次比較，總比較次數為 `n * (n-1) / 2`。
  - 因此，時間複雜度為 O(n²)。這在最佳、最差和平均情況下都是一樣的。

- **空間複雜度 (Space Complexity): O(1)**
  - 選擇排序是一種 **原地排序 (in-place)** 演算法。
  - 它只需要一個額外的變數 (`min_idx`) 來儲存最小值的索引，因此所需的額外空間是固定的，與輸入資料的大小無關。
