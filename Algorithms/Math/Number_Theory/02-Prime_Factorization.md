# 數論核心：質因數分解

質因數分解是將一個正整數寫成一系列質數的乘積的過程。根據算術基本定理，任何大於 1 的自然數，要麼本身是質數，要麼可以被唯一地分解為質數的乘積。這是許多數論問題的核心。

## 1. 核心算法：基於 O(sqrt(n)) 的試除法

質因數分解的算法與質數判斷一脈相承，同樣利用了「一個合數 `n` 必有一個小於等於 `sqrt(n)` 的質因數」這一性質。

**算法流程**:

1. 從最小的質數 2 開始，嘗試整除 `n`。
2. 如果 `n % i == 0`，說明 `i` 是 `n` 的一個質因數。我們將 `i` 記錄下來，然後用 `n` 除以 `i`，得到新的 `n`，繼續對新的 `n` 進行這個過程（即 `while (n % i == 0)`），直到 `n` 不再能被 `i` 整除。
3. `i` 遞增，繼續尋找下一個質因數。
4. 重複此過程，直到 `i` 大於 `sqrt(n)`。
5. **最後的處理**: 如果經過上述步驟後，`n` 仍然大於 1，那麼這個剩餘的 `n` 本身也必然是一個質數（因為它沒有任何小於 `sqrt(n)` 的質因數）。

## 2. C++ 模板實現

這個模板可以高效地找出一個數的所有質因數及其個數。

```cpp
#include <vector>
#include <map>

/**
 * @brief 對一個正整數進行質因數分解
 *
 * @param n 要分解的正整數
 * @return std::map<int, int> 一個映射，鍵是質因數，值是該質因數的指數
 */
std::map<int, int> primeFactorize(int n) {
    std::map<int, int> factors;
    if (n <= 1) {
        return factors;
    }

    // 從 2 開始試除
    // 同樣使用 i * i <= n 來避免浮點運算和溢出問題
    for (int i = 2; (long long)i * i <= n; ++i) {
        // 如果 i 是 n 的因數，則持續除以 i
        while (n % i == 0) {
            factors[i]++;
            n /= i;
        }
    }

    // 如果 n 在除法後仍然大於 1，說明 n 本身就是一個質因數
    // 這種情況發生在 n 是一個較大的質數，或者其最大質因數大於 sqrt(n) 時
    if (n > 1) {
        factors[n]++;
    }

    return factors;
}
```

### 數據結構選擇

- **`std::map<int, int>`**: 非常適合用來存儲結果。鍵 (key) 代表質因數，值 (value) 代表該質因數的冪次（指數）。`map` 會自動對質因數進行排序，輸出結果清晰。
- **`std::vector<std::pair<int, int>>`**: 如果不需要自動排序，或者對性能有極致要求，`vector` 也是一個可行的選擇。

### 示例

```cpp
int num = 84;
std::map<int, int> result = primeFactorize(num);
// result 將會是:
// {
//   2: 2,  // 2^2
//   3: 1,  // 3^1
//   7: 1   // 7^1
// }
// 因為 84 = 2^2 * 3 * 7
```

## 3. 算法正確性解釋

- **為什麼 `i` 一定是質數？**
  當我們檢查 `i` 是否能整除 `n` 時，所有比 `i` 小的質因數都已經被從 `n` 中除盡了。例如，當 `i` 到達 4 時，`n` 必然已經不能被 2 整除；當 `i` 到達 6 時，`n` 必然已經不能被 2 和 3 整除。因此，任何能整除當前 `n` 的 `i`，都不會是合數，它必然是一個質數。

## 4. 應用場景

質因數分解是解決許多數論問題的基礎，例如：

- 計算一個數的所有因數（約數）。
- 計算一個數的因數個數或因數之和。
- 判斷兩個數的關係，如是否互質。
- 解決與最大公因數 (GCD) 和最小公倍數 (LCM) 相關的複雜問題。
