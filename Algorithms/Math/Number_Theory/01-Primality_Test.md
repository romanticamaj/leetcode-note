# 數論基礎：質數判斷

質數判斷是數論問題的基石。一個大於 1 的自然數，如果除了 1 和它自身以外不再有其他因數，則稱這個數為質數（或素數）。

## 1. 核心思想

判斷一個數 `n` 是否為質數，最直觀的方法就是「試除法」：檢查從 2 到 `n-1` 的所有整數是否能整除 `n`。如果在此過程中找到任何一個能整除 `n` 的數，則 `n` 不是質數。如果遍歷完畢都沒有找到，則 `n` 是質數。

## 2. 算法優化：從 O(n) 到 O(sqrt(n))

樸素的試除法效率低下。我們可以進行一個關鍵的優化：

**核心洞察**: 如果一個數 `n` 可以被分解為 `n = a * b`，那麼 `a` 和 `b` 中至少有一個數小於或等於 `sqrt(n)`。

**證明**: 假設 `a` 和 `b` 都大於 `sqrt(n)`，那麼 `a * b > sqrt(n) * sqrt(n) = n`，這與 `a * b = n` 矛盾。

因此，我們只需要檢查從 2 到 `sqrt(n)` 的所有整數即可。如果在這個範圍內沒有找到 `n` 的因數，那麼在 `(sqrt(n), n)` 的範圍內也絕不可能找到，因為它的配對因數必然小於 `sqrt(n)`，而這種情況已經被排除了。

## 3. C++ 模板實現

這是 LeetCode 中最常用、最高效的質數判斷模板。

```cpp
#include <cmath>

/**
 * @brief 判斷一個整數是否為質數 (O(sqrt(n)) 優化)
 *
 * @param n 要判斷的整數
 * @return true 如果 n 是質數
 * @return false 如果 n 不是質數
 */
bool isPrime(int n) {
    // 質數定義：大於 1 的自然數
    if (n <= 1) {
        return false;
    }

    // 從 2 遍歷到 sqrt(n)
    // 注意：i * i <= n 的寫法可以避免使用浮點數 sqrt()，
    // 同時也能有效防止 i * i 在 i 較大時發生整數溢出（如果 n 接近 INT_MAX）。
    // 如果擔心溢出，可以使用 (long long)i * i <= n。
    for (int i = 2; i * i <= n; ++i) {
        // 如果找到因數，則不是質數
        if (n % i == 0) {
            return false;
        }
    }

    // 如果循環結束都沒有找到因數，則是質數
    return true;
}
```

### 關鍵實現細節

1. **邊界條件**: `n <= 1` 的情況必須首先處理。根據定義，1、0 和所有負數都不是質數。
2. **循環條件**: `i * i <= n` 是比 `i <= sqrt(n)` 更優的寫法。
   - **性能**: 它避免了每次循環都調用 `sqrt()` 函數，該函數涉及浮點運算，通常比整數乘法慢。
   - **精度**: 避免了浮點數可能帶來的精度問題。
   - **溢出考量**: 當 `n` 非常大時（例如接近 `INT_MAX`），`i * i` 可能會溢出。在這種情況下，應將 `i` 轉換為 `long long` 進行比較：`for (long long i = 2; i * i <= n; ++i)`。對於 LeetCode 的中等難度題目，`int` 通常足夠。

## 4. 適用場景

- 當需要對單個、數值不是特別巨大的數字進行質數判斷時，`O(sqrt(n))` 的方法是最高效、最實用的。
- 如果需要對一個範圍內的大量數字進行質數判斷（例如，找出 1 到 1,000,000 內的所有質數），則應使用更高效的「篩法」，如 Sieve of Eratosthenes。
