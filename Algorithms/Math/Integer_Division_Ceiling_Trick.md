# 演算法技巧：整數除法的無條件進位 (Ceiling Trick)

在演算法競賽和軟體開發中，我們經常需要在不使用浮點數的前提下，計算兩個正整數相除的“無條件進位”值（即 `ceil(a / b)`）。一個非常高效且廣泛使用的技巧是 `(a + b - 1) / b`。

## 問題場景

標準的 C++ 整數除法 `/` 會自動捨去小數部分（向零取整）。

- `7 / 3` -> `2`
- `6 / 3` -> `2`

但很多時候我們需要的是向上取整的效果：

- `ceil(7 / 3.0)` -> `3`
- `ceil(6 / 3.0)` -> `2`

直接使用浮點數 `ceil` 函數（如 `std::ceil`）可能會引入精度問題，且效率較低。

## 解決方案：整數技巧

對於任意兩個正整數 `a` 和 `b`，計算 `ceil(a / b)` 的等效整數運算為：

```cpp
(a + b - 1) / b
```

### 案例分析

讓我們用 `a = 7, b = 3` 來驗證：

- `(7 + 3 - 1) / 3`
- `9 / 3`
- `3` (正確)

用 `a = 6, b = 3` 來驗證：

- `(6 + 3 - 1) / 3`
- `8 / 3`
- `2` (正確)

### 為什麼這個技巧有效？

這個技巧的核心是**將分子 `a` 巧妙地“推高”**，使得在進行截斷除法時，能夠補償被捨去的部分。

我們可以分兩種情況討論：

1. **`a` 可以被 `b` 整除 (a % b == 0)**
   - 在這種情況下，`a` 可以寫成 `a = k * b`，其中 `k` 是整數。
   - 代入公式：`(k*b + b - 1) / b`
   - `= ((k+1)*b - 1) / b`
   - 由於 `(k+1)*b` 可以被 `b` 整除，那麼 `(k+1)*b - 1` 除以 `b` 的商就是 `k`。
   - 結果為 `k`，與 `a / b` 的結果相同。

2. **`a` 不可以被 `b` 整除 (a % b != 0)**
   - 在這種情況下，`a` 可以寫成 `a = k * b + r`，其中 `r` 是餘數 (`1 <= r <= b-1`)。
   - 代入公式：`(k*b + r + b - 1) / b`
   - `= ((k*b + b) + (r - 1)) / b`
   - `= ((k+1)*b + (r - 1)) / b`
   - 因為 `1 <= r <= b-1`，所以 `0 <= r-1 <= b-2`。
   - 這意味著 `(r-1)` 是一個非負數且嚴格小於 `b`。
   - 因此，`((k+1)*b + (r - 1))` 除以 `b` 的商就是 `k+1`。
   - 結果為 `k+1`，這正是 `ceil(a / b)` 的正確值。

**總結：** `+ b - 1` 這個操作確保了：當 `a` 能被 `b` 整除時，它不會改變商；而當 `a` 不能被 `b` 整除時，它剛好能將商“推”到下一個整數。

## 適用範圍

- 此技巧適用於**正整數** `a` 和 `b`。
- 在處理負數時需要特別小心，因為不同語言對負數除法的取整行為可能不同。
