# 心法：利用整數除法統一計算中位數索引

在處理已排序陣列的中位數問題時，一個常見的邏輯分支是判斷陣列大小的奇偶性，然後根據結果計算一或兩個中心索引。然而，利用 C++（及類似語言）的整數除法特性，我們可以將這個過程統一為一個無分支的優雅形式。

## 傳統方法：區分奇偶

傳統的思路是：

1. 檢查 `size` 是奇數還是偶數。
2. **如果 `size` 是奇數**：中位數索引是 `size / 2`。
3. **如果 `size` 是偶數**：中位數是兩個中心元素的平均值，索引分別是 `size / 2 - 1` 和 `size / 2`。

這種方法雖然直觀，但在程式碼中需要 `if-else` 分支，增加了複雜性。

## 統一心法：`(size - 1) / 2` 與 `size / 2`

**核心心法**：對於一個 **0-based** 的已排序陣列，無論其大小為奇數或偶數，兩個中心（或同一個中心）的索引總是 `(size - 1) / 2` 和 `size / 2`。

這個技巧的精髓在於「**先對 size 減一再除以二**」，它巧妙地利用了整數除法會自動向下取整的特性。

### 運作原理與範例

讓我們看看這個心法在奇數和偶數大小下的表現：

- **當 `size` 為偶數 (例如 `size = 4`)**:
  - 第一個索引：`(4 - 1) / 2 = 3 / 2 = 1`
  - 第二個索引：`4 / 2 = 2`
  - 結果：索引 `1` 和 `2`，完全正確。

- **當 `size` 為奇數 (例如 `size = 5`)**:
  - 第一個索引：`(5 - 1) / 2 = 4 / 2 = 2`
  - 第二個索引：`5 / 2 = 2`
  - 結果：兩個計算都指向同一個中心索引 `2`，完全正確。

```cpp
// 應用範例
#include <vector>
#include <iostream>

void find_median_indices(int size) {
    if (size == 0) {
        std::cout << "Empty array" << std::endl;
        return;
    }
    int index1 = (size - 1) / 2;
    int index2 = size / 2;
    std::cout << "For size " << size << ", median indices are: " << index1;
    if (index1 != index2) {
        std::cout << " and " << index2;
    }
    std::cout << std::endl;
}

int main() {
    find_median_indices(4); // 輸出: For size 4, median indices are: 1 and 2
    find_median_indices(5); // 輸出: For size 5, median indices are: 2
}
```

這個方法消除了 `if-else`，讓程式碼更簡潔，也降低了因邊界條件判斷錯誤而引發 bug 的風險。

## 延伸：1-based 索引的計算

在某些特殊場景（例如，某些演算法的描述或非 C++ 環境）中，如果需要處理 **1-based** 索引，這個心法同樣可以延伸。

**核心心法 (1-based)**：兩個中心索引是 `(size + 1) / 2` 和 `(size + 2) / 2`。

- **當 `size` 為偶數 (例如 `size = 4`)**:

  - 第一個索引：`(4 + 1) / 2 = 5 / 2 = 2`
  - 第二個索引：`(4 + 2) / 2 = 6 / 2 = 3`
  - 結果：第 `2` 和第 `3` 個元素，正確。

- **當 `size` 為奇數 (例如 `size = 5`)**:
  - 第一個索引：`(5 + 1) / 2 = 6 / 2 = 3`
  - 第二個索引：`(5 + 2) / 2 = 7 / 2 = 3`
  - 結果：第 `3` 個元素，正確。

## 重要前提

此處要求 `size > 0`，公式中的分子皆非負，因此 C++ 整數除法向零截斷的結果等同向下取整。Python 的整數除法 `//` 是向下取整，在這個非負範圍也得到相同結果；不要將兩種語言在負數上的行為視為相同。
