# DP 問題形式：如何識別動態規劃問題

本文件旨在闡述動態規劃 (Dynamic Programming) 問題的常見形式，並提供與貪心算法 (Greedy Algorithm) 的比較，以幫助你更準確地識別何時應使用 DP。

---

## 1️⃣ DP 問題的典型特徵

當你遇到一個問題，並發現它具備以下一個或多個特徵時，它很可能是一個 DP 問題。

### (1) 求解最佳值或計數 (Asking for an optimal value or the number of ways)

DP 問題通常要求計算一個「最佳值」或「總方法數」。

- **最佳值 (Optimal Value):**
  - 求**最大 (maximum)** 或**最小 (minimum)** 的結果。
  - 例如：「最長遞增子序列」、「最小編輯距離」、「最大利潤」。
- **方法數 (Number of Ways):**
  - 計算達成某一目標的**總共有多少種方法**。
  - 例如：「爬樓梯的方法數」、「解碼方法總數」。

### (2) 每一步都需要做決策 (Decisions affect future decisions)

問題的解決過程可以被分解為一系列的步驟，在每一步都需要做出一個「決策」。

- **決策影響未來：** 最關鍵的是，當前步驟的決策會直接影響後續步驟的可用選項或狀態。這創造了決策之間的依賴性。
- **例子 (House Robber):** 在第 `i` 間房子，你需要決策「搶」或「不搶」。
  - 如果**搶**，下一棟房子就不能搶 (`i+1`)，你只能從 `i+2` 開始考慮。
  - 如果**不搶**，你可以從 `i+1` 開始考慮。
  - 這個決策鏈條正是 DP 狀態轉移的核心。

---

## 2️⃣ DP vs. Greedy：關鍵區別

Greedy 和 DP 都用於解決優化問題，但其核心哲學截然不同。混淆這兩者是常見的錯誤。

| 特徵         | 動態規劃 (Dynamic Programming)                                                     | 貪心算法 (Greedy Algorithm)                                                            |
| :----------- | :--------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------- |
| **決策依據** | 考慮所有子問題的最優解，做出**全域最優**的決策。                                   | 只根據**當前局部最佳**的選擇做出決策，不考慮未來。                                     |
| **決策影響** | **當前決策會影響未來決策**。需要權衡不同選擇對後續狀態的影響。                     | **當前決策是獨立的，不影響未來決策**。做出的選擇是最終的，不可撤銷。                   |
| **核心思想** | 「我該如何選擇，才能讓**整體**結果最好？」                                         | 「我現在能做的**最好**的選擇是什麼？」                                                 |
| **例子**     | **0/1 背包問題**：在容量限制下，需要權衡放入哪個物品對剩餘空間和總價值的長遠影響。 | **分數背包問題**：每次都選擇單位價值最高的物品，這個局部最優選擇最終會導向全域最優解。 |

### 如何識別？

問自己一個關鍵問題：**「我現在做出的這個看似最佳的選擇，會不會讓我錯過未來的某個更好的整體解？」**

- 如果答案是 **「會」** 或 **「不確定」**，那麼這很可能是一個 DP 問題。你需要探索所有可能的決策路徑，並從中找出最優解。
- 如果答案是 **「不會」**，即每個階段的局部最優選擇都能確保最終得到全域最優解，那麼這是一個 Greedy 問題。

> **總結：** Greedy 做出的是一系列**局部最優**的選擇，期望它們能構成一個**全域最優**解。而 DP 則是探索所有決策，確保找到真正的**全域最優**解。
