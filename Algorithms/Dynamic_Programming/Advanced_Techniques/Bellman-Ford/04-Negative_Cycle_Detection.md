# Bellman-Ford：演算法限制與負權重環檢測

雖然 Bellman-Ford 是一個強大且通用的最短路徑演算法，但其主要限制和一個關鍵特性在於它如何處理負權重環。

---

## 1. 演算法的限制

Bellman-Ford 演算法僅適用於從源點可達的範圍內**沒有負權重環**的圖。

- **為什麼？** 如果圖中包含一個負權重環，傳統意義上的「最短」路徑便不存在。我們可以無限次地遍歷這個負權重環，使得路徑權重變得任意小（趨近於-∞）。在這種情況下，Bellman-Ford 無法給出一個有限的最短路徑值，但它可以可靠地檢測出這種情況。

---

## 2. Bellman-Ford 如何檢測負權重環

儘管 Bellman-Ford 演算法無法在有負權重環的圖中找到最短路徑，但它可以檢測出是否存在這樣的環。

### 檢測方法

檢測是在主要的 `V-1` 輪鬆弛操作**完成之後**執行的。

1. **`V-1` 輪的保證**: 如前所述，如果圖中沒有負權重環，經過 `V-1` 輪完整的鬆弛後，`dist` 陣列將收斂到所有可達頂點的真正最短路徑值。此時不應再有任何鬆弛的可能。

2. **第 `V` 輪檢查**: 我們對所有邊再執行最後一輪，即第 `V` 輪的鬆弛操作。

3. **判斷條件**: 在第 `V` 輪中，如果我們發現任何邊 `(u, v)` 仍然滿足鬆弛條件：

   **`dist[u] + weight(u, v) < dist[v]`**

   ...這意味著我們**仍然**可以找到一條更短的路徑。

4. **結論**: 既然 `V-1` 輪對於一個沒有負權重環的圖來說已經足夠找到最短路徑，那麼在第 `V` 輪仍能成功進行鬆弛，就是一個直接的證據，證明圖中存在一個從源點可達的負權重環。這是因為在一條路徑的邊數超過 `V-1` 後還能縮短其長度，唯一的方法就是遍歷一個淨權重為負的環。

### C++ 實作片段

這段邏輯通常放在 Bellman-Ford 演算法主迴圈之後。

```cpp
// 主迴圈 (V-1 次迭代) 在此完成...
// for (int i = 0; i < n - 1; ++i) { ... }

// 執行第 V 輪檢查以檢測負權重環。
for (const auto& edge : edges) {
    int u = edge[0];
    int v = edge[1];
    int weight = edge[2];

    if (dist[u] != INF && dist[u] + weight < dist[v]) {
        // 如果仍然可以鬆弛一條邊，則存在負權重環。
        // 處理錯誤：返回 false、拋出異常等。
        return false;
    }
}

// 如果程式執行到這裡，表示沒有檢測到負權重環。
return true;
```
