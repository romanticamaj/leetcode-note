# DP 的圖論統一視角：將動態規劃視為圖遍歷

動態規劃的許多複雜概念，可以透過一個簡單而強大的模型來統一：將問題視為在一個**有向無環圖 (Directed Acyclic Graph, DAG)** 上的遍歷。這個視角不僅澄清了 Top-Down 與 Bottom-Up 方法的內在聯繫，還提供了一個強大的工具來設計和除錯我們的狀態轉移邏輯。

---

## 1. 核心概念：狀態空間圖 (The State-Space Graph)

所有 DP 問題的內在結構，都可以抽象為一個狀態空間圖：

- **節點 (Nodes):** 代表問題中每一個唯一的「狀態」。例如，`dp[i]` 或 `dp[i][j]`。
- **有向邊 (Directed Edges):** 代表狀態之間的「轉移關係」。一條從狀態 A 到狀態 B 的邊，意味著計算 B 的解需要用到 A 的解。

這個圖必須是**有向無環圖 (DAG)**，因為：

- **有向性**來自「最優子結構」，即問題的解依賴於其子問題的解，這是一個單向的依賴關係。
- **無環性**是 DP 可解的根本前提。如果存在循環依賴（例如，A 依賴 B，B 又依賴 A），則問題無解，無法構成有效的遞迴關係。

### 狀態圖 vs. 計算樹

這個內在的狀態圖與暴力遞迴的「計算樹」有本質區別：

- **狀態圖**是問題固有的、唯一的結構，每個狀態節點只出現一次。
- **計算樹**是暴力遞迴的執行過程展開。如果存在重疊子問題，同一個狀態節點會在計算樹中以不同節點的形式重複出現，導致冗餘計算。

> DP 的本質，就是直接在這個唯一的狀態圖上進行計算，並確保每個節點只被求解一次，從而避免了暴力遞迴的冗餘。

---

## 2. 方法論的圖論類比：DFS vs. 拓撲排序

當我們確立了狀態圖模型後，Top-Down 和 Bottom-Up 這兩種 DP 方法，可以驚人地對應到兩種經典的圖遍歷演算法。

| 方法論                     | 圖論類比                                | 描述                                                                                                                                                                                                               |
| :--------------------------- | :-------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Top-Down (Memoization)**   | **狀態圖上的深度優先搜尋 (DFS)**        | 從我們想知道的「最終目標狀態」開始，進行遞迴呼叫，這相當於在圖上從一個節點出發，深度探索其依賴的路徑。`cache` 的作用就是記錄訪問過的節點，避免重複探索，本質上是在做剪枝。此方法只會訪問從目標狀態**可達**的節點。 |
| **Bottom-Up (Tabulation)**   | **狀態圖的拓撲排序 (Topological Sort)** | 從「基礎案例」（在圖中沒有入度的節點）開始，按照依賴順序，層層推進，計算所有狀態的值。這確保了在計算任何節點之前，它所依賴的所有節點都已經被計算完畢，這正是拓撲排序的核心思想。此方法會計算圖中的**所有**節點。   |

---

## 3. 實戰應用：用圖模型進行除錯

這個類比不僅是理論上的，它還提供了一個強大的工具來驗證和除錯你的 DP 設計。

> **心法**：如果你不確定你的狀態設計是否正確，試著視覺化你的 Bottom-Up 填表過程。**如果你無法定義一個清晰、無歧義的迭代順序（即拓撲序），這強烈暗示你的狀態設計可能存在問題**：
>
> - **缺少依賴關係**：你的狀態定義可能遺漏了某個關鍵變數，導致無法確定唯一的計算路徑。
> - **循環依賴**：你的狀態轉移方程可能導致了 A 依賴 B，同時 B 又依賴 A 的情況，這在狀態圖中形成了環 (cycle)，使得拓撲排序無法進行。一個有效的 DP 問題，其狀態圖必須是無環的 (DAG)。
