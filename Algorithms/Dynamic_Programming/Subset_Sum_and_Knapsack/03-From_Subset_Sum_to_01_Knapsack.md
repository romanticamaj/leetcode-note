# 從 Subset Sum 到 0/1 Knapsack 最佳化

**先保留「項目進度 × 數值限制」與選／不選的骨架，再依輸出目標，決定每個狀態存可行性還是最佳值。**

本篇接回 *Algorithm Design* §6.4 的路線：容量內最大總重量，再將重量與價值分開，成為 0/1 Knapsack。

## 1. 從恰好可達，轉向容量內最佳值

前兩篇的 Subset Sum 判定版問：「只用前 i 個項目，能否恰好湊出 w？」每格存 bool。

現在改問：「只用前 i 個項目，總重量不超過 c 時，能取得的最大總重量是多少？」每格存最佳重量，記為 `B(i,c)`。

這裡的 c 是容量上限，不是必須恰好填滿的重量。原始問題的容量為 C，子問題則需要不同的剩餘容量 c；這正是 recurrence 中額外變數的角色。

| | 恰好可達 P(i,w) | 容量內最佳重量 B(i,c) |
|---|---|---|
| 數值軸 | 必須恰好達成的總和 | 允許使用的容量上限 |
| 狀態值 | true／false | 最佳可達總重量 |
| 沒有項目時 | 只有目標 0 可達 | 任意非負容量下，最佳重量皆為 0 |
| 多種選擇如何合併 | OR | max |

## 2. Adding a Variable 的必要性仍然一樣

若只記 `B(i)`，選了目前重量 w[i-1] 後，無法表達前 i-1 個項目只能使用 `c-w[i-1]` 容量的子問題。

因此保留 `B(i,c)`，且定義目前項目重量 x=w[i-1]：

```text
B(0,c) = 0

若 x > c：B(i,c) = B(i-1,c)
若 x ≤ c：B(i,c) = max(B(i-1,c), x + B(i-1,c-x))
```

不選目前項目，容量保留；選取目前項目，取得 x 的重量，同時剩下 c-x 的容量。兩種候選都是在回答相同容量上限下的最佳總重量，因此可用 max 比較。

恰好目標 T 的判定，可由 `B(n,T)==T` 得到：最佳值不超過 T，等於 T 就代表存在恰好填滿的子集。這是兩個問題的連結，不表示它們的表格語義相同。

## 3. 再加上獨立的 value：標準 0/1 Knapsack

現在每個項目有重量 w[i] 與價值 v[i]，每個最多選一次；總重量不超過 C 時，要最大化總價值。先假設重量是正整數、價值非負，且允許不選任何項目。

定義：**`K(i,c)`＝只用前 i 個項目，總重量不超過 c 時的最大總價值。**

令 x=w[i-1]、y=v[i-1]：

```text
K(0,c) = 0

若 x > c：K(i,c) = K(i-1,c)
若 x ≤ c：K(i,c) = max(K(i-1,c), y + K(i-1,c-x))
```

和上一節相比，**佔用容量仍扣重量 x，取得收益則改加價值 y**。若重量與價值本來相同，就退回最大總重量問題。

## 4. 為什麼通常不需要再加一個 value 維度？

在這個模型下，同樣的 i 與容量上限 c，未來可用項目與容量限制已經確定；我們要比較的是在該限制內誰的價值最大，因此最佳價值是狀態的答案，不必同時作為 key。

這不是「value 永遠不能當維度」。若題目增加獨立的價值門檻或其他限制，就要重新設計；不能只因為看到 weight、value 兩個輸入欄位，就機械地開三維表。

**選擇的效果可能分成兩種角色：改變剩餘問題的資訊放進 state；要累積、比較的結果放進 state value。**

## 5. range、memoization 與 table 如何接續？

1. 原始容量是 C，合法剩餘容量 c 在 `0..C`；重量不合的選取分支不進入。
2. 相同 `(i,c)` 的限制相同，因此可共用最佳答案。
3. Memoization 依需要算子問題；bottom-up 依 i=0..n 安排前綴表。
4. base case 為 `K(0,c)=0`，答案為 `K(n,C)`。

不是換成最佳化問題就必須重新發明一套填表方式；先更新狀態回傳值、選取收益與聚合運算，再檢查原有依賴是否仍成立。

標準二維表時間與空間皆為 O(n(C+1))，在每格常數成本模型下成立。C 的數值大小是否可負擔，是下一篇獨立分析的問題。

## ⚠️ 不同輸出，不共用同一種初始化

- 恰好湊出的 bool 版本，需要區分可達與不可達；零個項目只可達 0。
- 容量上限下求最大非負價值，空集合對每種非負容量都合法，最佳值為 0。
- 若改成「必須恰好用完容量」的最佳化，不能把所有格子都當成可行的 0；不可達需要獨立表示。
- 方法數是計數問題，依互斥選擇累加；不能直接把 OR 改成 max 就當成同一個問題。

## ✅ 讀完應能重建的脈絡

**恰好可達 → 容量內最大總重量 → 重量與價值分離 → 容量內最大總價值。**

骨架始終是每個項目選或不選；改變的是數值軸的限制語義與每格要回傳的結果。
