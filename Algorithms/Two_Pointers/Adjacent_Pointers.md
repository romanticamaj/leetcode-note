# Adjacent Pointers (相鄰指針)

Adjacent Pointers 是 Two Pointers 技巧的一種變體，也是 K-Gap Pointers 的特殊情況（k=1），其中兩個指針相鄰或保持固定的小間距（通常是 1），並以相同的速度移動。這種技巧特別適用於需要就地修改數據結構（如反轉鏈表）的情況。

## 核心概念

- 兩個指針相鄰或保持 1 個元素的間距 (1-gap pointers)
- 兩個指針以相同的速度移動 (speed 一樣)
- 通常一個指針指向當前處理的元素，另一個指針指向前一個元素或下一個元素
- 適用於需要就地修改數據結構的情況，如反轉鏈表、交換相鄰元素等

## 基本模板

```cpp

ListNode* fn(ListNode* head) {
    ListNode* prev = nullptr;  // 前一個節點
    ListNode* curr = head;     // 當前節點
    
    while (curr) {
        ListNode* next = curr->next;  // 暫存下一個節點

        // 操作指標
        // ...
        
        // 移動指針
        prev = curr;
        curr = curr->next;
    }
    
    // ...
}
```

## 關鍵設計要素

### 1. While Condition (終止條件)

Adjacent Pointers 的終止條件通常基於當前指針的有效性：

```cpp
while (curr) {
    // 操作...
}
```

這個條件確保：
- `curr` 不為 nullptr，所以可以安全地訪問 `curr->next`
- 當 `curr` 到達鏈表末尾時，循環結束

**設計原則**：
- 分析循環內部的指針操作，確保條件能防止任何不安全的訪問
- 考慮邊界情況，如空鏈表、單節點鏈表等
- 確保終止條件與問題的目標一致

### 2. While Loop Movement (前進條件)

Adjacent Pointers 的前進條件通常是：

```cpp
prev = curr;
curr = curr->next;
```

這個移動模式確保：
- 兩個指針始終保持相鄰關係
- 每次迭代都向前推進一步
- 指針移動前，已經完成了當前節點的必要操作

**設計原則**：
- 在移動指針前，確保已經完成了當前節點的所有必要操作
- 保持指針之間的相鄰關係
- 確保移動方式能夠幫助解決特定問題（如反轉鏈表）

## 優勢

- **就地修改**：可以在不使用額外空間的情況下修改數據結構
- **簡單直觀**：實現簡單，邏輯清晰
- **空間效率**：只需要 O(1) 的額外空間
- **適用性廣**：可以應用於多種需要就地修改的問題
