# Prefix Sum 技巧

## 要點

- 創建一個前綴和數組 **prefix**，其中 **prefix[i]** 是所有元素到索引 i（包含）的總和
- Prefix Sums 允許我們在 **O(1)** 時間內找到任何子數組的和
- 如果我們想要從索引 i 到 j（包含）的子數組的和，答案是 **prefix[j] - prefix[i - 1]**
- 有時會遇到 i - 1 越界的情況，可以用 **prefix[j] - prefix[i] + nums[i]**
- 用線條來畫出 sum，會比較好想像

## 效率分析

建立前綴和是一種預處理形式：
- 只需 **O(n)** 時間來建立
- 允許所有未來的子數組查詢在 **O(1)** 時間內完成
