# 演算法技巧：前綴和與二分搜尋的結合 (Prefix Sum + Binary Search)

## 核心思想

當一個問題需要在一個陣列中尋找一個**連續子陣列 (subarray)**，使其**總和**滿足特定條件時，「前綴和 + 二分搜尋」是一個非常強大的 `O(n log n)` 解題模式。

1. **前綴和 (Prefix Sum):** 首先，我們花費 `O(n)` 的時間預處理出一個前綴和陣列 `prefix`。`prefix[i]` 儲存了原始陣列從 `nums[0]` 到 `nums[i]` 的總和。這使得我們可以在 `O(1)` 的時間內查詢任意子陣列 `[i, j]` 的和：

   - `sum(i, j) = prefix[j] - prefix[i-1]` (當 `i > 0`)
   - `sum(0, j) = prefix[j]`

2. **二分搜尋 (Binary Search):** 如果前綴和陣列具有**單調性**（例如，當原始陣列所有元素均為正數時，前綴和陣列必然是嚴格遞增的），我們就可以在其上高效地進行二分搜尋。這包含兩種主要應用：
   - **直接查找：** 尋找是否存在一個索引 `i` 使得 `prefix[i]` 等於某個特定值 `value`。
   - **條件查找：** 如下文所述，遍歷陣列並為每個元素尋找滿足特定條件的對應前綴和。

---

## 通用問題模式

假設問題是：**找到一個子陣列 `[i, j]`，使其總和 `sum(i, j)` 滿足某個條件，例如 `sum(i, j) >= target`。**

1. **轉化條件:**

   - `sum(i, j)` 可以用前綴和表示為 `prefix[j] - prefix[i-1]`。
   - 條件變為 `prefix[j] - prefix[i-1] >= target`。
   - 移項後得到 `prefix[i-1] <= prefix[j] - target`。

2. **演算法流程:**

   - 計算整個陣列的前綴和 `prefix`。
   - 遍歷 `prefix` 陣列的每一個位置 `j`（從 `0` 到 `n-1`）。
   - 對於每個 `prefix[j]`，我們需要在其左側 `[0, j-1]` 的範圍內，尋找一個滿足 `prefix[i-1] <= prefix[j] - target` 的索引 `i`。
   - 由於 `prefix` 陣列是單調的，這個尋找過程就可以用**二分搜尋**來完成，時間複雜度為 `O(log n)`。

3. **總時間複雜度:** `O(n)` 遍歷 + 每次 `O(log n)` 搜尋 = `O(n log n)`。

---

**注意:** 「前綴和 + 二分搜尋」是一個更具普適性的技巧。雖然某些問題（如 LeetCode 209）有更優的 `O(n)` 滑動窗口解法，但該解法通常要求陣列元素為正。而前綴和結合二分搜尋的模式，即使在陣列包含負數時，只要前綴和陣列本身具有單調性，依然可以適用。
