# DFS 複雜度分析：通用模型（圖與樹的比較）

---

## 🧠 核心心法

分析 DFS 複雜度的關鍵與 BFS 相同：**每個節點（vertex）和每條邊（edge）都只會被訪問一次**。

> **心法**：無論是遞迴還是迭代實現，我們都依賴 `visited` 陣列（或集合）來避免重複訪問。一個節點一旦被標記為 `visited`，就不會再次進入該節點的探索邏輯。

---

## 🕒 時間複雜度 (Time Complexity)

時間複雜度主要由兩部分組成：

1. **節點訪問**：所有節點 `V` 都會被訪問一次。
2. **邊的探索**：對於每個節點，我們都會探索其所有的鄰接邊。

### 通用公式：`O(V + E)`

- **V**：圖中的節點總數（Number of Vertices）。
- **E**：圖中的邊總數（Number of Edges）。

### 分析過程

- 每個節點 `v` 都會被 `dfs(v)` 函數（或等效的迭代邏輯）呼叫一次。
- 在 `dfs(v)` 內部，我們會遍歷節點 `v` 的所有鄰居。在整個 DFS 過程中，所有節點的鄰居（即所有邊）都會被檢查一次。
- 對於**有向圖**，所有邊的總和是 `E`。
- 對於**無向圖**，每條邊 `(u, v)` 會被檢查兩次（從 `u` 探索到 `v`，以及從 `v` 探索到 `u`），總共是 `2 * E`。
- 因此，總時間複雜度為 `O(V + E)`。

### 特殊情況：格狀圖 (Lattice/Grid Graph)

- 在 `M x N` 的格狀圖中，`V = M * N`。
- 每個節點最多有 4 個（或 8 個）鄰居，所以 `E` 的數量級約等於 `4 * V`。
- 因此，複雜度為 `O(V + E) = O(M*N + 4*M*N) = O(M * N)`。
- **速記**：對於格狀圖，時間複雜度就是**格子總數**。

### 不同圖表示法的影響

- **鄰接列表 (Adjacency List)**：這是最標準的情況，遍歷鄰居的成本與節點的度（degree）成正比。總和起來就是 `O(V + E)`。
- **鄰接矩陣 (Adjacency Matrix)**：要找到一個節點的所有鄰居，你需要遍歷一整行，成本是 `O(V)`。因此，總時間複雜度變為 `O(V * V) = O(V^2)`。
- **邊列表 (Edge List)**：通常會先將其轉換為鄰接表以便於 DFS，轉換成本為 `O(E)`。之後的 DFS 複雜度仍為 `O(V + E)`。

## 💾 空間複雜度 (Space Complexity)

空間複雜度主要由**三部分**組成：

1. **圖的表示 (Graph Representation)**: 如果輸入只有邊列表 (edge list)，我們通常需要先建立一個鄰接表 (adjacency list)，這會佔用額外空間。
2. **`visited` 陣列**: 需要一個與節點數量相當的空間來記錄訪問狀態。
3. **遞迴呼叫堆疊 (Recursion Stack)** 或**顯式堆疊 (Explicit Stack)**: 這是 DFS 與 BFS 空間複雜度的主要區別。

### 通用公式：`O(V + E)`

- **圖的表示**: 建立鄰接表需要儲存所有的邊，空間為 `O(E)`。對於有 `V` 個節點的圖，至少需要 `O(V)` 的空間來儲存節點本身，所以總空間是 `O(V + E)`。
- **`visited` 陣列**: 需要 `O(V)` 的空間。
- **遞迴/顯式堆疊**:
  - 在最壞情況下，DFS 可能會沿著一條路徑一直走到底，直到遍歷完所有節點。
  - 這條路徑的長度可能等於圖中所有節點的數量 `V`（例如，在一個鏈狀圖中）。
  - 因此，遞迴呼叫堆疊的深度或顯式堆疊的大小可能達到 `O(V)`。

- **總體分析**:
  - 總空間 = `O(V + E)` (鄰接表) + `O(V)` (visited) + `O(V)` (堆疊)
  - 因此，整體空間複雜度為 **`O(V + E)`**。如果圖是隱式給出的（不需要額外建圖），則退化為 `O(V)`。

### 特殊情況：格狀圖 (Lattice/Grid Graph)

- `V = M * N`。
- `visited` 陣列需要 `O(M * N)` 的空間。
- 堆疊的最大深度可能是在格狀圖中走出最長的路徑，最壞情況下是 `M * N`（例如，蛇形遍歷）。
- 總體空間複雜度仍為 `O(M * N)`。

---

## 🌳 樹的複雜度分析 (Tree)

樹是一種特殊的圖，其中 `E = V - 1`。

- **時間複雜度**：`O(V + E) = O(V + V - 1) = O(V)`。
  - **速記**：對於樹，時間複雜度就是**節點總數**。
- **空間複雜度**：`O(H)`，其中 `H` 是樹的高度（the height of the tree）。
  - 在**完全二叉樹**中，`H = log(V)`，所以空間複雜度為 `O(log V)`。
  - 在一個**極度不平衡**的樹（skewed tree，類似鏈表）中，`H = V`，所以空間複雜度為 `O(V)`。
  - 這是 DFS 在處理平衡樹時比 BFS 空間效率更高的關鍵原因（BFS 是 `O(W)`，W 是寬度）。

---

## ✅ 總結

| 結構類型   | 時間複雜度 | 空間複雜度          |
| :--------- | :--------- | :------------------ |
| **通用圖** | `O(V + E)` | `O(V + E)`          |
| **格狀圖** | `O(M * N)` | `O(M * N)`          |
| **樹**     | `O(V)`     | `O(H)` (H=樹的高度) |

這個分析模型適用於大多數標準的 DFS 問題。
