# 串流處理（Stream Processing）

**串流處理（Stream Processing）** 是一種即時處理資料流的技術，適用於需要低延遲反應的大型 Web 應用，如即時監控、推薦系統、金融交易等。

---

## 🔄 批次處理 vs 串流處理

| 特性     | 批次處理（Batch）  | 串流處理（Stream） |
| -------- | ------------------ | ------------------ |
| 資料來源 | 靜態檔案、大批資料 | 持續產生的資料流   |
| 延遲     | 高（分鐘～小時）   | 低（毫秒～秒）     |
| 適用場景 | 報表、歷史分析     | 即時監控、警示系統 |

---

## 🧩 串流處理架構組件

### 1. 資料來源（Source）

- 例如：感測器、使用者行為、伺服器日誌、Kafka topic

### 2. 處理引擎（Processing Engine）

- 負責轉換、過濾、聚合資料
- 常見工具：Apache Flink、Apache Spark Streaming、Kafka Streams

### 3. 資料接收端（Sink）

- 將處理結果輸出至資料庫、儀表板、通知系統等

---

## 🧠 核心概念

- **事件時間（Event Time）** vs **處理時間（Processing Time）**
- **視窗（Windowing）**：將資料流切成時間區段進行聚合
- **狀態管理（Stateful Processing）**：保留中間狀態以支援累積計算
- **容錯（Fault Tolerance）**：透過 checkpoint 與重播機制確保資料不遺失

---

## ✅ 小結

串流處理是建構即時反應系統的關鍵技術，能讓系統即時洞察與決策。選擇合適的工具與設計模式，能大幅提升系統的即時性與可靠性。
