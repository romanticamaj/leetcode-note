# Orthogonality 解題心法（精華版）

## 📌 什麼是正交性？

**正交性（Orthogonality）= 將問題拆成多個彼此獨立的軸線（dimensions），每一軸單獨思考，最後自由組合成解法。**

### 🎯 核心目標

- ✅ 降低思考複雜度
- ✅ 避免糊成一團
- ✅ 像積木一樣組裝解法
- ✅ 讓 5 分鐘內建立「解法骨架」變得可行

---

## 🧩 正交性在 LeetCode 常見題型中的應用

### A. Dynamic Programming (DP)

DP 可拆成三個完全獨立的軸線：

| 軸線           | 內容                                          |
| -------------- | --------------------------------------------- |
| **State**      | 你要記錄什麼                                  |
| **Transition** | 狀態如何變化                                  |
| **Traversal**  | 用什麼順序計算（top-down/bottom-up/空間壓縮） |

> 💡 想清楚三軸後再組合即可。

---

### B. Sliding Window

兩軸正交組合：

| 軸線               | 內容                                       |
| ------------------ | ------------------------------------------ |
| **Data Structure** | 維護 window 狀態的結構（map/set/counter…） |
| **Logic**          | expand → shrink → update 的條件與流程      |

> 💡 資料結構與邏輯互不干擾。

---

### C. Binary Search (Binary Search on Answer)

二分題一定能拆成兩軸：

| 軸線                     | 內容                                 |
| ------------------------ | ------------------------------------ |
| **Search Space**         | 你要二分什麼（index/答案/threshold） |
| **Feasibility Function** | `check(mid)` 如何判斷可行            |

> 💡 決定 search space 與設計 check 完全獨立。

---

### D. Graph / Tree Traversal

兩軸：

| 軸線                    | 內容                      |
| ----------------------- | ------------------------- |
| **Representation**      | 如何儲存圖（list/matrix） |
| **Traversal Algorithm** | DFS / BFS / shortest path |

> 💡 表示法不影響遍歷策略。

---

### E. Greedy

兩軸：

| 軸線                  | 內容             |
| --------------------- | ---------------- |
| **Ordering Strategy** | 按什麼排序       |
| **Decision Rule**     | 每一步的局部決策 |

---

### F. Backtracking / DFS

三軸：

| 軸線                     | 內容             |
| ------------------------ | ---------------- |
| **State Representation** | 狀態如何表示     |
| **Choices**              | 每一步有哪些選擇 |
| **Pruning**              | 如何剪枝優化     |

---

## ⏱️ 正交性帶來的解題流程

| 階段                     | 任務                       |
| ------------------------ | -------------------------- |
| **1. 辨識題型 → 拆軸線** | 識別問題類型，確定獨立軸線 |
| **2. 各軸獨立思考**      | 分別設計每個軸線的解決方案 |
| **3. 組裝成完整解法**    | 將各軸線組合成完整實作     |

---

## ✨ TL;DR

> **正交性 = 把複雜題拆成獨立軸線（State / Transition / Traversal…），每軸單獨設計，最後組合成解法。幾乎所有 LeetCode 題型都能用正交思維拆解。**

---

## 📚 延伸思考

正交性思維不僅適用於演算法問題，更是軟體工程中的重要設計原則。透過將複雜問題分解為獨立的維度，我們可以：

- 🎯 更清晰地理解問題本質
- 🔧 更靈活地調整解決方案
- 🧪 更容易地測試和除錯
- 📈 更快速地迭代和優化
