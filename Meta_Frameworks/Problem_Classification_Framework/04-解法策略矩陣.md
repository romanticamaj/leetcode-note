| Complexity Bound | 建議技術 | 使用情境 |
|-----------------|---------|---------|
| **O(1)** | Hash Lookup, Math Formula | 直接計算、查找 |

## 🎯 技術選擇決策樹 (Technique Selection Decision Tree)

### 步驟 1: 檢查 Constraint
```
O(log n) 需求？ → Binary Search or Balanced BST
O(1) space 需求？ → Two Pointers or In-place
已排序輸入？ → Binary Search or Two Pointers
```

### 步驟 2: 檢查 Intent
```
Boolean → Validation, Search
Counting → DP, Combinatorics
Optimization → DP, Greedy, Binary Search
Construction → Backtracking, Recursion
Selection → Hash Map, Heap, Binary Search
Transformation → Two Pointers, Recursion
```

### 步驟 3: 檢查 Domain 特定模式
```
Tree → DFS/BFS, Recursion
Graph → DFS/BFS, Shortest Path Algorithms
Interval → Sweep Line, Merge
```

### 步驟 4: 驗證 Cross-Cutting Patterns
```
Interval Pattern → Sweep Line
Path Pattern → DP, DFS
Search Space → Backtracking, Binary Search
```

## ✅ 技術驗證檢查表 (Technique Validation Checklist)

| 技術 | 驗證問題 |
|------|---------|
| **DP** | 有重疊子問題？能定義遞迴關係？ |
| **Greedy** | 局部最優 → 全域最優？能用 Exchange Argument 證明？ |
| **Binary Search** | 有單調性？能分 Valid/Invalid？ |
| **Backtracking** | 狀態空間可探索？需要所有解？ |
| **Two Pointers** | 有不變量？單調性質？ |
| **Sliding Window** | 連續子陣列/子字串？單調性質？ |
| **DFS/BFS** | 需要圖遍歷？BFS 用於最短？DFS 用於訪問順序？ |
| **Union-Find** | 需要動態連通性？集合合併？ |
| **Topological Sort** | 是 DAG？有依賴關係？ |

**使用方式**：
1. 根據 Intent 和 Domain 查找主要矩陣
2. 檢查 Constraint 是否排除某些選項
3. 使用決策樹進行最終選擇
4. 用檢查表驗證技術適用性
