# 快速決策地圖 (Quick Decision Map)

**純決策邏輯 | 零範例 | 心法導向**

---

## 🎯 30秒分類流程 (30-Second Classification)

```
Intent (問什麼?) → Domain (什麼結構?) → Statefulness (記憶?) → Constraint (限制?) → Technique
```

---

## 1️⃣ Intent 識別 (Intent Recognition)

**核心問題：問題要求什麼輸出？**

| Intent | 關鍵字 | 第一直覺 |
|--------|--------|---------|
| **Boolean** | can, is, exists, possible, valid | Graph 可達性 / Set 檢查 |
| **Counting** | count, ways, number of | DP / Combinatorics |
| **Optimization** | min, max, shortest, longest | DP / Greedy / Binary Search |
| **Construction** | build, return the... | Backtracking / Greedy 建構 |
| **Selection** | find, choose, pick | Binary Search / Heap |
| **Transformation** | convert, rearrange | Two Pointers / Simulation |

---

## 2️⃣ Structure/Domain 識別 (Structure Recognition)

**核心問題：處理什麼資料結構或概念空間？**

| Structure | 訊號 | 常用技術 |
|-----------|------|---------|
| **Sequence** (陣列/字串) | array, string, 順序重要 | DP, Two Pointers, Sliding Window, Binary Search |
| **Graph** | nodes, edges, paths, grid neighbors | DFS/BFS, Dijkstra, Union-Find, Topological Sort |
| **Tree** | parent-child, hierarchy, BST | Tree DP, Traversal, LCA |
| **Interval** (區間) | ranges, start/end, overlapping | Sweep Line, Greedy Merge |
| **Grid** (矩陣) | 2D array, coordinates, neighbors | BFS (最短), DFS (可達), DP |
| **Set** | unique, distinct, frequency | Hash, Multiset, Bitmask |

**隱式圖形 (Implicit Graphs)**：狀態轉換、Grid 移動、依賴關係、變換

---

## 3️⃣ Statefulness 分析 (Statefulness Level)

**核心問題：需要記憶什麼？記憶範圍多大？**

| Level | 特徵 | 技術 |
|-------|------|------|
| **Stateless** (無狀態) | 一次掃描、無需記憶 | Sort, Greedy Scan |
| **Local** (局部狀態) | 最近 k 個元素 | Two Pointers, Sliding Window, Monotonic Stack/Queue |
| **Global** (全域狀態) | 所有子問題 | DP, Memoization |
| **Event-Driven** (事件驅動) | 時間排序 | Sweep Line, Priority Queue |

---

## 4️⃣ Constraint 對應 (Constraint Mapping)

**核心問題：約束條件指向什麼技術？**

| Constraint 類型 | 技術指向 |
|----------------|---------|
| **Resource** (資源：預算、容量) | Knapsack DP, Greedy |
| **Ordering** (順序：A 在 B 前) | Topological Sort |
| **Positional** (位置：Grid 邊界) | Coordinate DP/BFS |
| **Compositional** (組合：從部分建構) | DP, Divide & Conquer |
| **Structural** (結構：連通性) | DFS/BFS, Union-Find |
| **Temporal** (時間：時間窗口) | Sweep Line, Scheduling |

---

## 5️⃣ Complexity 驅動選擇 (Complexity-Driven Choice)

**核心問題：n 的範圍允許什麼複雜度？**

| n 範圍 | 最大複雜度 | 允許技術 |
|--------|-----------|---------|
| ≤10 | O(n!) | Backtracking, Permutations |
| ≤20 | O(2^n) | Bitmask DP, Subset Enumeration |
| ≤100 | O(n³) | Floyd-Warshall, 3D DP |
| ≤1000 | O(n²) | 2D DP, All Pairs |
| ≤10⁵ | O(n log n) | Sort, Binary Search, Heap, Segment Tree |
| ≤10⁶ | O(n) | Hash, Prefix Sum, Union-Find |
| >10⁶ | O(log n) / O(1) | Math, Binary Search Only |

## 6️⃣ 決策規則表 (Quick Decision Rules)

### 輸入特性 (Input Properties)
```
已排序 (Sorted)      → Binary Search, Two Pointers
未排序 (Unsorted)    → 先 Sort 或用 Heap
加權圖 (Weighted)    → Dijkstra (≥0) / Bellman-Ford
無權圖 (Unweighted)  → BFS 最短路徑
DAG                 → Topological Sort, DAG DP
樹 (Tree)           → DFS/BFS, Tree DP
```

### 問題模式 (Problem Patterns)
```
"k-th element"              → Quick Select, Heap, Binary Search
"All pairs"                 → O(n²) DP, Floyd-Warshall
"All subsets/permutations"  → Backtracking
"Subarray sum = k"          → Prefix Sum + Hash
"Longest/shortest substring"→ Sliding Window, DP
"Valid parentheses"         → Stack
"Count inversions"          → Merge Sort
"Range queries"             → Prefix Sum, Segment Tree
"Median in stream"          → Two Heaps
"Top k"                     → Heap, Bucket Sort
"Detect cycle"              → Floyd's / DFS Coloring
"Shortest path all-pairs"   → Floyd-Warshall
```

### 約束驅動 (Constraint-Driven)
```
k 個約束 + n 個元素     → O(n log k) Heap
Range Queries          → Prefix Sum, Segment Tree
Point Updates          → Fenwick Tree
連通性 (Connectivity)  → Union-Find
單調性 (Monotonicity)  → Greedy, Binary Search
順序重要               → Sequence DP
順序無關               → Combinatorial DP
```

## 8️⃣ 技術驗證檢查表 (Technique Validation)

| 技術 | 何時使用 | 驗證方式 |
|------|---------|---------|
| **Two Pointers** | Sequence, 雙向/同向 | 不變量成立 |
| **Sliding Window** | 連續子陣列/子字串 | 單調性質 |
| **Binary Search** | 已排序或單調函數 | Valid/Invalid 分界 |
| **Greedy** | 局部最優 → 全域最優 | Exchange Argument |
| **DP** | 重疊子問題 | 定義遞迴關係 |
| **Backtracking** | 所有解、CSP | 狀態空間可探索 |
| **DFS/BFS** | Graph 遍歷 | DFS: 訪問順序 / BFS: 最短 |
| **Dijkstra** | 加權、非負、單源 | 非負權重 |
| **Union-Find** | 連通性、分組 | 集合成員查詢 |
| **Topological Sort** | DAG、依賴關係 | 無環 |
| **Sweep Line** | Intervals、事件 | 事件可排序 |
| **Monotonic Stack** | Next Greater/Smaller | 最近邊界 |

## 9️⃣ DP 狀態設計模式 (DP State Design Patterns)

**Sequence (序列)**：
- `dp[i]` = 以 i 結尾
- `dp[i][j]` = 範圍或約束

**Tree (樹)**：
- `dp[node][0/1]` = 包含/排除
- `dp[node]` = 子樹

**Graph (圖)**：
- `dp[node][state]` = 節點+狀態
- `dp[mask]` = 子集合

**Grid (矩陣)**：
- `dp[i][j]` = 格子
- `dp[i][j][state]` = 格子+狀態

## 💡 使用心法 (Usage Tips)

1. **從 Intent 開始**：輸出類型是最直接的線索
2. **Domain 確認結構**：決定可用操作和自然表示
3. **Statefulness 定範圍**：決定記憶策略
4. **Constraint 給提示**：往往直接指向技術
5. **Complexity 做驗證**：確保技術可行
