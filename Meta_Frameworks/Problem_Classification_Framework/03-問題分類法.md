# 問題分類法 (Problem Classification)

**無範例 | 純概念 | 系統化分類**

---

## 📌 分類維度總覽 (Classification Dimensions)

本文件定義四個分類維度：
1. **Intent (意圖)** - 問題要求什麼輸出？
2. **Domain (領域)** - 處理什麼資料結構？
3. **Constraint (約束)** - 有什麼限制條件？
4. **Cross-Cutting Patterns (跨領域模式)** - 什麼抽象模式？

---

## 🎯 Intent 分類 (Intent Taxonomy)

### 1. Boolean Intent (判斷意圖)
**定義**：判斷真假、驗證有效性、檢查可行性  
**關鍵字**：can, is, exists, possible, valid, check, determine  
**典型技術**：DFS/BFS (連通性), DP (可行性), Stack (驗證), Two Pointers (配對), Cycle Detection

### 2. Counting Intent (計數意圖)
**定義**：計算數量、方法數、可能性總數  
**關鍵字**：count, ways, number of, how many, total  
**典型技術**：DP (計數), Combinatorics (組合數學), DFS/BFS (枚舉), Math (公式)

### 3. Optimization Intent (最佳化意圖)
**定義**：尋找最大值、最小值、最長、最短  
**關鍵字**：min, max, longest, shortest, best, optimal, minimize, maximize  
**典型技術**：DP (最佳化), Greedy (貪心), Binary Search (單調), Dijkstra (最短路徑), Kadane's Algorithm

### 4. Construction Intent (建構意圖)
**定義**：建立、生成、建構特定結構  
**關鍵字**：construct, build, generate, create, produce, design  
**典型技術**：Backtracking (生成所有), Recursion (結構建構), Greedy (增量建構), DFS (遍歷建構)

### 5. Selection Intent (選擇意圖)
**定義**：找到、選擇、識別特定元素  
**關鍵字**：find, select, choose, identify, locate, kth, top k  
**典型技術**：Hash Map (查找), Binary Search (已排序), Heap (Top K), Quickselect (第 K 個), Two Pointers (配對)

### 6. Transformation Intent (轉換意圖)
**定義**：轉換、修改、重排輸入形式  
**關鍵字**：convert, transform, reverse, rotate, sort, modify, rearrange  
**典型技術**：Two Pointers (原地), Recursion (結構轉換), In-place Manipulation, Bit Manipulation

## 🏗️ Domain 分類 (Domain Taxonomy)

### 1. Array Domain (陣列領域)
**定義**：線性索引序列、連續記憶體  
**關鍵字**：array, sequence, indexed, linear  
**典型技術**：DP, Two Pointers, Binary Search, Sliding Window, Prefix Sum

### 2. String Domain (字串領域)
**定義**：字元序列、文字處理  
**關鍵字**：string, text, character, substring  
**典型技術**：DP, Sliding Window, Two Pointers, Stack, Hash Map, KMP

### 3. Matrix Domain (矩陣領域)
**定義**：二維網格、座標系統  
**關鍵字**：matrix, grid, 2D array, coordinates  
**典型技術**：BFS (最短), DFS (可達), DP (路徑), In-place Rotation

### 4. Tree Domain (樹領域)
**定義**：階層結構、父子關係  
**關鍵字**：tree, binary tree, BST, parent-child, hierarchy  
**典型技術**：DFS, BFS, Recursion, Tree DP, Traversal (Inorder/Preorder/Postorder)

### 5. Graph Domain (圖領域)
**定義**：任意連接、節點與邊  
**關鍵字**：graph, nodes, edges, paths, connected, cycle  
**典型技術**：DFS/BFS, Dijkstra, Bellman-Ford, Topological Sort, Union-Find, Floyd-Warshall

### 6. Interval Domain (區間領域)
**定義**：範圍、時間段、起始結束  
**關鍵字**：interval, range, start, end, overlapping, merge  
**典型技術**：Sweep Line, Sort + Greedy, Merge, Binary Search (查詢)

### 7. LinkedList Domain (鏈結串列領域)
**定義**：指標基礎序列、非連續記憶體  
**關鍵字**：linked list, node, next, pointer  
**典型技術**：Fast/Slow Pointers, Two Pointers, Recursion, Iteration

### 8. Set Domain (集合領域)
**定義**：無序集合、唯一性、頻率  
**關鍵字**：set, unique, distinct, frequency, collection  
**典型技術**：Hash Set/Map, Bitmask, Multiset, Bucket Sort

## ⚖️ Constraint 分類 (Constraint Taxonomy)

### 1. Resource Constraint (資源約束)
**定義**：時間/空間複雜度、容量限制、預算  
**關鍵字**：O(n), O(1) space, capacity, budget, limited  
**影響**：決定允許的演算法複雜度類別

### 2. Ordering Constraint (順序約束)
**定義**：順序要求、優先權、依賴關係  
**關鍵字**：order, before, after, precedence, dependencies  
**典型技術**：Topological Sort, DP (順序), Priority Queue

### 3. Positional Constraint (位置約束)
**定義**：位置規則、邊界、相鄰關係  
**關鍵字**：position, adjacent, boundary, neighbor, coordinate  
**典型技術**：Coordinate DP, BFS (Grid), Positional Indexing

### 4. Compositional Constraint (組合約束)
**定義**：如何從部分建構整體、分割規則  
**關鍵字**：partition, subset, composition, decomposition  
**典型技術**：DP (分割), Backtracking (組合), Divide & Conquer

### 5. Structural Constraint (結構約束)
**定義**：形狀、連通性、結構特性要求  
**關鍵字**：connected, balanced, acyclic, shape, property  
**典型技術**：DFS/BFS (連通), Union-Find (分組), Structural Validation

### 6. Temporal Constraint (時間約束)
**定義**：時間窗口、事件順序、時間關係  
**關鍵字**：time window, schedule, event, temporal, timing  
**典型技術**：Sweep Line (事件), Priority Queue (排程), Event Processing

## 🔀 Cross-Cutting Patterns (跨領域模式)

### 1. Interval Pattern (區間模式)
**定義**：管理範圍、合併區間、區間查詢  
**關鍵字**：range, interval, merge, overlap  
**跨領域性**：出現在 Array, Graph, Scheduling 等多領域  
**典型技術**：Sweep Line, Sort + Merge, Binary Search

### 2. Path Pattern (路徑模式)
**定義**：帶選擇的序列、決策序列  
**關鍵字**：path, sequence with choices, route  
**跨領域性**：Tree paths, Graph paths, DP 狀態轉移  
**典型技術**：DFS, DP, Backtracking

### 3. Partition Pattern (分割模式)
**定義**：分組、劃分、切割  
**關鍵字**：partition, split, divide, group  
**跨領域性**：Array 分割, Graph 分組, Set 劃分  
**典型技術**：DP (分割), Quickselect (Partition), Union-Find (分組)

### 4. Matching Pattern (配對模式)
**定義**：元素配對、匹配、對應  
**關鍵字**：match, pair, corresponding, mapping  
**跨領域性**：括號配對, 圖匹配, 字串匹配  
**典型技術**：Stack (括號), Hash Map (對應), Bipartite Matching

### 5. Aggregation Pattern (聚合模式)
**定義**：資訊組合、累積、彙總  
**關鍵字**：aggregate, combine, accumulate, collect  
**跨領域性**：Prefix Sum, Tree 聚合, Graph 聚合  
**典型技術**：Prefix Sum, Tree DP (Post-order), Segment Tree

### 6. Search Space Pattern (搜尋空間模式)
**定義**：探索可能性、狀態空間搜尋  
**關鍵字**：search space, explore, state space, possibilities  
**跨領域性**：Backtracking, Binary Search on Answer, State Space BFS  
**典型技術**：Backtracking, Binary Search (答案), BFS (狀態)

## 💡 分類心法 (Classification Principles)

### Intent 決定 DP 狀態類型
```
Boolean:      dp[i] = true/false
Counting:     dp[i] = count (SUM transition)
Optimization: dp[i] = min/max value (MIN/MAX transition)
```

### Domain 決定可用操作
```
Array:  索引、Sliding Window、Binary Search
Tree:   Parent-child、Traversal、Subtree
Graph:  Edges、Connectivity、Shortest Path
```

### Constraint 直接指向技術
```
O(log n)         → Binary Search
O(n) + 已排序    → Two Pointers
連通性           → Union-Find
依賴關係         → Topological Sort
```

### Cross-Cutting 啟發抽象
```
看到 intervals   → 想到 Sweep Line
看到 paths       → 想到 DP/DFS
看到 partition   → 想到 DP (分割)
看到 matching    → 想到 Stack/Hash Map
```

## 🎯 應用流程 (Application Flow)

1. **讀題 → 識別 Intent**：問題最終要求什麼？
2. **看輸入 → 識別 Domain**：處理什麼資料結構？
3. **找限制 → 識別 Constraint**：有什麼約束條件？
4. **找模式 → 識別 Cross-Cutting**：有什麼通用抽象？
5. **查矩陣 → 選擇技術**：Intent × Domain → Technique
6. **驗證 → Complexity 檢查**：技術複雜度符合 n 範圍？
