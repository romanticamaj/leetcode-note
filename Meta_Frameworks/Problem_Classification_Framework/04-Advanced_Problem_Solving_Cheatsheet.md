## 0. 用法說明

- 這份心法把任何題目拆成 **四面向：Task / Structure / Statefulness / Constraints**。
- **Structure 是建模，不是資料結構實作**。先決定題目世界，再選工具。
- 面試中：先用 [2. 決策樹] 30–60 秒完成粗判，再用各章細化。

---

## 1. 四面向判型總覽

1. **Task（任務）**：

   - 計數（#ways）
   - 布林判斷（存在性/可達/等價/覆蓋）
   - 最值（最短/最長/最大/最小/最少步數）
   - 構造/轉換（輸出序列/重建結構/把 X 變 Y）

2. **Structure（世界）**：

   - 序列（array/string/linked list）
   - 集合/多重集合（set/multiset/hashmap）
   - 區間（interval/segment/calendar）
   - 圖（有向/無向、DAG、加權/不加權、樹/森林、隱性圖）
   - 矩陣/網格（grid/board）
   - 流式/線上（streaming/sliding window）

3. **Statefulness（狀態可記憶性）**：

   - 無狀態（一次掃描/排序/指標不變量）
   - 局部狀態（雙指標/滑動窗/單調結構）
   - 全域/歷史狀態（DP/記憶化/位元壓縮/自動機）
   - 事件驅動（掃描線/優先佇列）

4. **Constraints（限制）**：

   - n 上限 & 目標複雜度（10^5 暗示 O(n)~O(n log n)）
   - 值域大小（小值域 → 計數/位壓；大值域 → 雜湊/平衡樹/離散化）
   - 查詢模式（單次/多次/線上/離線）
   - 記憶體上限、是否需要模數

> 流程：**Task → Structure → Statefulness × Constraints**。

## 2. 30–60 秒決策樹

1. 題目在問 **存在/計數/最值/構造** 哪一種？
2. 世界像 **圖 / 區間 / 序列 / 網格** 哪種？是否**隱性圖**？
3. 只需 **局部狀態** 就能維持不變量？還是要 **DP/記憶化**？
4. 限制允許的複雜度與資料結構等級是什麼？
5. 套路候選：

   - 不加權最少步：**BFS**；加權：**Dijkstra/0-1 BFS**
   - 重疊/會議室/最少資源：**掃描線 + PQ**
   - 最長/最短子陣列滿足條件：**滑動窗/單調佇列**
   - 合併/下一個更大/面積：**單調棧**
   - 子集/分割/編輯距離：**DP**
   - 多筆區間查詢：**Fenwick/Segment Tree**
   - 排序可證最優：**貪心（交換引理）**

## 3. Structure 判型雷達

| 訊號詞/結構       | 典型關鍵詞                   | 標準套路                 | 不變量/要點                              |
| ----------------- | ---------------------------- | ------------------------ | ---------------------------------------- |
| **隱性圖**        | 一步變換、最少步、可達、課表 | BFS / 拓墣 / 最短路      | 訪問標記、層數=步數、入度=可修課數       |
| **區間系統**      | 重疊、資源、房間、行程       | 排序+掃描線 / PQ / 差分  | 事件+1/-1、同時刻順序、合併條件 `<`/`<=` |
| **序列窗口**      | 最長/最短滿足子陣列          | 雙指標/滑動窗/單調佇列   | 窗口不變量（需求計數、單調性）           |
| **單調結構**      | 下一個更大/面積/雨水         | 單調棧                   | 每元素進出一次、攤銷 O(1)                |
| **字串匹配/相似** | 子序列、編輯距離、模式       | KMP/Z / DP               | 前綴函數、遞推邊界                       |
| **Grid 搜尋**     | 島嶼、擴散、權重             | DFS/BFS/0-1 BFS/Dijkstra | 多源初始化、方向集、邊權 0/1             |
| **多查詢聚合**    | 區間和/最值、在線            | Fenwick/SegTree/離線     | 低維聚合、lazy、離散化                   |
| **幾何/掃描**     | 面積、交叉、最近對           | 掃描線/分治/旋轉卡尺     | 事件序、鄰近候選維護                     |

## 4. Task → 標準解法對照

- **Counting（#ways）**：DP（索引/容量/餘數/位壓），要模數就加 mod。
- **Boolean（存在性/可達）**：記憶化 DFS / 背包 DP / BFS（不加權最短步）。
- **Optimization**：

  - 最少步/最短路：BFS / Dijkstra / Bellman-Ford（有負）/ 0-1 BFS。
  - 最大值/最長路：DP（DAG 上可做）/ 單調結構 / 貪心（可證）。
  - 匹配/流：二分圖匹配、最大流最小割（Dinic/Edmonds-Karp）。

- **Construct/Transform**：

  - 要「最少操作」→ 建狀態圖做 BFS。
  - 只要「是否可行/最小代價」→ DP/最短路。
  - 判等/同構 → 正規化（排序、頻率向量、hash 簽名）。

## 5. Backtracking → Top-Down → Bottom-Up 轉換心法

1. **定義最小充分狀態**：`state = (pos / 容量 / 差值 / 餘數 / mask / 指標)`
2. **決策分支**：選/不選、放置位置、下一步轉移。
3. **剪枝**：

   - 上界估計（若最佳可能值 ≤ 當前最佳則剪）
   - 去重（排序 + 跳相同簇、狀態簽名）
   - 早停（需求達成即可縮窗/返回）

4. **轉 DP（若只需可行/計數/最值）**：把回溯副作用收斂成 `f(state)` 值或布林；加 memo。
5. **轉 Bottom-Up**：

   - 找到拓撲順序（索引/容量/節點入度為 0）
   - 空間優化（滾動陣列/位元集）
   - 嚴格定義轉移只依賴先前層。

6. **狀態唯一性與 cache 設計**：

   - Key 只包含「會影響未來」的最小資訊。
   - 大值域 → 離散化；多維 → 觀察單調性、可分離性降維。

## 6. 測試設計（等價類 / 邊界 / 角落）

- **等價類**：空/單一/全相等/全不同/已排序/重複多/值域極小/極大。
- **邊界值**：n=0/1/2、窗口剛滿/剛不滿、容量剛好等。
- **角落案例**：

  - 圖：單節點、全連通、完全不連通、多源、多路交會點。
  - 區間：同起點/同終點、巢狀、端點閉開一致性。
  - 字串：重複字元、回文、交錯。

- **不變量驗證**：

  - 滑動窗容量與需求餘量
  - 單調棧遞增/遞減性
  - 兩堆大小差不超 1
  - Union-Find parent/size 正確性

- **對拍**：小規模暴力/回溯；隨機測資 + hash 比對。

---

## 7. 複雜度槓桿與常用降維

- 用 **排序** 取代雙層迴圈（O(n log n) 代替 O(n²)）。
- **滑動窗** 把所有子陣列枚舉 →O(n) 維護特性。
- **單調結構**：每元素進出一次，攤銷 O(1)。
- **前綴/差分/位元集**：查詢 O(1)；字母小集可用 bitset 優化。
- **二分答案**：在答案域上二分 + 可行性檢查。
- **分塊/Mo's/離線**：把難的在線查詢換成可重排的離線。
- **DAG 化**：圖 DP 先拓撲排序，避免重算。
- **幾何掃描**：把 O(n²) 交互變 O(n log n)。

---

## 8. 常見陷阱與糾錯清單

- 把 **布林/最值/計數** 混用：先鎖定需求再定義回傳型別。
- **狀態不唯一** 或 key 過大導致爆記憶體/重算。
- **排序比較器** 非傳遞/不自洽。
- **開閉區間** 混亂；合併條件 `<` vs `<=`。
- **圖**：點 vs 邊的 visited；多源初始化遺漏。
- **字串**：索引位移與邊界；大小寫/Unicode（若相關）。
- **DS 設計**：需求是 O(1) 結果拿 O(log n) 結構（反之亦然）。

## 9. 面試口條模板（無碼也能講清楚）

> 30 秒自動化口條

1. 這題我先歸類為 **[Task]** × **[Structure]**（看起來是 _存在性/最值/轉換_，而世界是 _隱性圖/區間/序列_）。
2. 限制看來 n≈**…**，目標複雜度 **O(… )**，不可能用 **O(n²)**。
3. 我會採用 **[套路]**，因為關鍵性質是 **[單調/最短/重疊/狀態唯一]**；不變量是 **[…]**。
4. 正確性：

   - 不變量：每步維持 **[…]**；
   - 最優性：**交換引理/割性質/拓撲順序**。

5. 測試：等價類 **a,b,c**；邊界 **…**；角落 **…**。若多查詢再升級 **Fenwick/SegTree/離線**。

## 10. 訓練計畫與題單映射（方向）

- **結構遷移練習**：同一 Structure 做不同 Task（如區間：merge → rooms → weighted scheduling）。
- **回溯 →DP**：先列舉全解，再改判定/計數，練習狀態最小化。
- **最短路三兄弟**：BFS→0-1 BFS→Dijkstra；再做 DAG 最長路 DP。
- **窗口三件套**：最短可行窗、最長可行窗、單調佇列取最值。
- **多查詢升級**：prefix → Fenwick → Segment Tree → lazy；再嘗試離線/Mo's。

# 附錄 A：一頁式速查表

**判型順序：**

1. **Task**：存在/計數/最值/構造？
2. **Structure**：圖/區間/序列/網格/隱性圖？
3. **Statefulness**：局部即可（窗/棧/堆）or 需要 DP？
4. **Constraints**：n、值域、查詢模式 → 目標複雜度與 DS 等級。

**雷達對照：**

- 最少步 & 一步變換 → **BFS（隱性圖）**
- 重疊/資源/會議室 → **掃描線 + PQ**
- 最長/最短子陣列 → **滑動窗 / 單調佇列**
- 下一個更大/面積/容器 → **單調棧**
- 子集/分割/編輯距離 → **DP（索引/容量/餘數/位壓）**
- 多次區間查詢 → **Fenwick / Segment Tree（+ 離散化）**
- 流/匹配/割 → **Dinic / 匈牙利 / 指派**

**不變量樣板：**

- 窗口：需求餘量、可行 ⇄ 不可行的邊界
- 單調棧：元素嚴格遞增/遞減；每元素進出一次
- 兩堆中位數：|L|-|R| ≤ 1 且 max(L) ≤ min(R)
- UF：parent 指向代表元；size/rank 維護

**複雜度槓桿：**

- 排序替代雙迴圈；二分答案；前綴/差分；bitset；離線；拓撲化

**測試清單（速念）**：

- 等價類：空/單/全同/全異/已排序/重複多/極值域
- 邊界：n=0/1/2、窗口臨界、容量臨界
- 角落：多源、多路交會、同端點、巢狀、回文/重複字

**面試口條（15 秒精簡版）：**

> 我把它歸為 **[Task] × [Structure]**。在這個限制下目標 **O(… )**。我選 **[套路]**，不變量是 **[…]**。正確性靠 **[交換引理/拓撲/割]**；測試含 **等價類/邊界/角落**。若多查詢我會升級到 **[Fenwick/SegTree/離線]**。
